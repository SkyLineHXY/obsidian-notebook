# π₀.₆: a VLA That Learns From Experience (RECAP)

> **论文**：arXiv:2511.14759v2（2025-11）
> **作者机构**：Physical Intelligence（Sergey Levine、Chelsea Finn、Karol Hausman 等 60 余人合著）
> **博客**：https://pi.website/blog/pistar06

---

## 研究问题

**Vision-Language-Action（VLA）模型**——如 π₀、π₀.₅、OpenVLA、GR00T——为通用机器人提供了 prompt 式任务指定能力。但它们大多只能达到**演示数据的上限水平**；要在真实部署中**像人一样通过练习精进**，需要：
1. **稳定、可扩展的 RL 方法**，兼容大参数量 VLA
2. **异构数据融合**：演示、自主 rollout、专家干预（intervention）
3. **真实世界奖励信号**：稀疏、模糊、含噪

已有工作的局限：
- 直接应用 PPO / REINFORCE 到大型 VLA 难以扩展
- 多数 RL-VLA 方法只支持**离散动作或简单高斯**，不适配 diffusion / flow 表达性策略
- 依赖纯 on-policy 数据，无法混合 off-policy 离线数据

---

## 核心贡献

### 方法：RECAP
**RL with Experience and Corrections via Advantage-conditioned Policies**

一个**端到端训练 VLA** 的迭代离线 RL 框架：

```
1. 数据收集：VLA rollout + 稀疏任务奖励 + 人类干预（HG-DAgger 风格）
2. 价值函数训练：多任务、语言条件化的分布式价值网络 V(o_t)
3. 优势条件化训练：把二值化的 advantage 作为 prefix token 喂给 VLA
```

关键数学背景：

$$
\hat\pi(a \mid o) \propto \pi_{\mathrm{ref}}(a \mid o)\, p(I \mid A_{\pi_{\mathrm{ref}}}(o, a))
$$

其中 $p(I|A)$ 是 advantage 的单调递增函数，保证 $J(\hat\pi) \ge J(\pi_{\mathrm{ref}})$。RECAP 不直接做策略梯度，而是把**优势**作为条件信息让 VLA 学习，"改进即条件"。

### 三阶段训练管线
1. **Pre-training**：在成千上万小时、多任务多机器人的大数据集上做 offline RL + advantage conditioning，得到基础模型 **π₀.₆**
2. **Task specialization**：针对下游任务用演示微调
3. **Iterative on-robot improvement**：自主执行 + 人工干预 → 更新 value → 更新策略（重复多轮）

### 模型：π₀.₆
- π₀.₅（上一代 VLA）升级：更大 backbone + 更多样条件输入
- 使用 **Flow Matching** 参数化动作头部
- 原生支持 **advantage conditioning**

## 实验结果（真实世界）

三个复杂长时序任务：

| 任务 | 亮点 |
|------|------|
| **家庭叠衣服** | 多种款式、软体织物；泛化到新房间新衣服 |
| **纸箱装配** | 扁平变形、需多步拼装；用于真实包装生产 |
| **制作咖啡** | 液体倾倒、操作专业意式咖啡机 |

主要数字：
- 任务吞吐（throughput）**翻倍以上**
- 失败率**减半**
- 实测运行时长：叠衣服 2 小时不间断；咖啡 13 小时连续运行

## 学术定位

RECAP 的独特组合：
1. **离线 RL 应用于大型 VLA**（而非小策略）
2. **Flow Matching 动作头 + 优势条件化**（规避 PG 训练难题）
3. **同时支持演示、自主 rollout、intervention 三类异构数据**

与 DPPO / FQL / ReinFlow 的根本差异：
- 后三者是**算法研究**，针对通用机器人策略
- RECAP 是**大模型 + 真实部署的系统级方案**，强调 scaling law 与 iteration loop
