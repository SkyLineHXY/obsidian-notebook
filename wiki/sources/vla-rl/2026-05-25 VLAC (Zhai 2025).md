# VLAC: A Vision-Language-Action-Critic Model for Robotic Real-World RL (Zhai 2025)

> Shaopeng Zhai, Qi Zhang, Tianyi Zhang, et al. Shanghai AI Lab.

[[raw/sources/papers/VLA+RL/Zhai 等 - 2025 - A Vision-Language-Action-Critic Model for Robotic Real-World Reinforcement Learning/Zhai 等 - 2025 - A Vision-Language-Action-Critic Model for Robotic Real-World Reinforcement Learning.md]]

---

## TL;DR

VLAC 在单一 InternVL 骨干内统一了 **actor**（动作生成）与 **critic**（任务进度奖励）两个角色。给定配对图像观察 + 语言目标，VLAC 输出 dense progress delta（signed 任务进度差值）作为 reward，以及 action tokens 用于执行。训练于 4000+ 小时多源数据，支持零样本 / 上下文学习的跨任务迁移。配合分级 human-in-the-loop 机制，在 4 项真实世界任务中 200 个 episode 内将成功率从 **∼30% 提升到 ∼90%**；引入 HIL 后样本效率再提升 50%，最高达 100% 成功。

## 核心问题

真实世界 VLA RL 面临两大瓶颈：
1. **稀疏奖励**：多数方法依赖任务特定的手工奖励 shaping，泛化差
2. **低效探索**：VLA 先验能力虽强，但早期探索无密集反馈，收敛慢

现有 dense reward 方法（VLM prompting、CLIP 嵌入距离、时序对比）在跨任务泛化、精细进度判断、或同 VLA 集成方面均有明显局限。

## VLAC 模型

### 架构

**Backbone**：InternVL（多模态大模型），单一模型同时生成 Reward Tokens 和 Action Tokens。

**Critic 输入**：配对图像 $(o_i, o_{i+\Delta t})$ + 语言任务描述 $l_\text{task}$ → 输出 **signed progress delta**：

$$
c_{i,i+\Delta t} = \text{VLAC}(o_i, o_{i+\Delta t};\, l_\text{task}) = \Delta t / (T - i) \in [-1, 1]
$$

此配对进度公式**不依赖全局起始点**，可用于任意轨迹子段，提升鲁棒性。

**三个辅助任务**：
- 任务描述生成（首末帧 → 语言 goal）
- 任务完成判断（$l_\text{done} \in \{0, 1\}$）
- 辅助感知任务（detection / segmentation / grounding / 3D contact cues）

### 训练数据

| 数据类型 | 规模 | 作用 |
|---|---|---|
| 语言-视觉理解数据 | 1M+ episode | 增强语义感知与推理 |
| 人类操作轨迹 | 3000h | 进度估计与任务理解 |
| 公开机器人数据集 | 1200h | 动作生成与任务 grounding |
| 自采机器人数据 | 15h+ | 精细进度标注 |
| 负例数据（大量构造） | — | 拒绝无关 prompt、检测回退或停滞 |

### 四类 Critic 数据构造策略

1. **Pair-wise Image Difference Filtering**：像素差 < 1% → 设 $c=0$，过滤静态帧
2. **Joint Sampling**：每对 $(o_i, o_{i+\Delta t})$ 同时构造正向/反向、精细/全局共 4 个样本
3. **Task Completion Joint Sampling**：平衡完成 / 未完成样本
4. **Cross-sampling**：5% 概率采样不匹配任务描述，设 $c=0$，增强语义辨别

## Real-World RL 框架

### 分级 Human-in-the-Loop（HIL）协议

VLAC 在真实机器人异步 RL 循环中部署，引入三级人工干预：

| 级别 | 操作 | 作用 |
|---|---|---|
| **Offline Demonstration Replay** | 重放预收集人类示教数据 | 解决早期探索困境，提供成功轨迹参考 |
| **Return and Explore** | 让机器人从失败状态回到起始，重新探索 | 降低探索空间复杂度 |
| **Human Guided Explore** | 人类远程引导机器人探索困难动作 | 针对低成功率场景补充高质量数据 |

### 规模化效率

随机器人数量 2→4→8 增加，每台机器人到达高成功率所需 episode 数持续下降——VLAC 支持多机并行探索。

## 实验结果

| Metric | Result |
|---|---|
| 真实任务成功率（4 任务） | 30% → **90%** (200 episodes) |
| HIL 加速样本效率 | 提升 **50%** |
| 最高成功率 | **100%**（含 HIL） |
| 基准评测（LIBERO-style sim） | VLAC actor 在 action generation 上可竞争 |

## 与相关方法对比

| 特征 | HIL-SERL (#22) | VLAC (#46) |
|---|---|---|
| RL 类型 | SAC / off-policy | PPO / on-policy token-level |
| Reward | Task-specific shaping | VLM 通用 progress delta |
| Actor 规模 | 小型专用策略 | 大型 VLA（InternVL） |
| 迁移性 | 少样本 real-world | 零样本 / 上下文学习 |
| Critic | Separate Q-network | Actor 同模型输出 reward token |
