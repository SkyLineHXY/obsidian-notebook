# Sci-VLA（Pang et al., 2026）

**标题**：Sci-VLA: Agentic VLA Inference Plugin for Long-Horizon Tasks in Scientific Experiments
**机构**：东南大学 计算机科学与工程学院 / Pattern Learning and Mining Lab（南京）
**关键词**：Vision-Language-Action Model · Robotic Lab · AI4Science

---

## 核心问题：科学实验中的 State Gap

机器人实验室是自主科学发现（AI4Science）的关键。科学实验多为**长程任务 = 多个原子任务（atomic tasks）重排组合**。作者观察到一个反直觉现象：

> **VLA 在科学任务上微调后，能可靠执行训练时见过的原子任务，却无法执行由这些已知原子动作重组而成的复合任务。**

根因是**训练时原子任务分布 ↔ 推理时复合任务分布的失配**：原子任务数据各自独立采集（每个从随机初始位姿开始），导致原子任务之间**缺少过渡轨迹**。第一个原子任务结束后，机械臂进入**分布外（OOD）状态**，VLA 在第二个原子任务起点卡死、持续抖动——即 **State Gap**。这说明 VLA "只记住了轨迹，并未真正理解任务"。

## 核心方法：推理插件（训练无关）

给定一个**已掌握原子任务**的微调 VLA，Sci-VLA 引入一个**仅在推理期介入**的 LLM agent 插件：当原子任务序列到来时，反复在任务间生成**过渡动作（transitional action）**并插入 VLA 输出的动作流。关键卖点：**Inference-Only ✓ / No Training ✓ / Data-Efficient ✓**。插件含两个交替运行的模块。

![[raw/sources/papers/VLA/Pang 等 - 2026 - Sci-VLA Agentic VLA Inference Plugin for Long-Horizon Tasks in Scientific Experiments/images/e47f9d03e4ceeb7555454a1aecc95fc54f46d729ed3f78f6655cd6e3e45542e5.jpg]]
*Figure 3：Sci-VLA 流水线。(1) Transitional Action Generation Module：用当前相机视图 + 下一原子任务描述检索目标关节位姿，交 LLM Agent 生成过渡动作代码；(2) Transition Action Insertion Module：断开 VLA → 插入过渡动作 → 重连 VLA，与 VLA 交替执行原子任务序列。*

### 模块 1：Transitional Action Generation（过渡动作生成）

VLA 推理停止时获取：当前关节位姿 $curr\_qpos$、当前主相机视图 $o_t^v$、下一原子任务描述 $o_{i+1}^l$。先从训练数据 $\mathcal{D}$ 抽取全部原子任务描述集 $\mathcal{P}=\{p_1,\dots,p_K\}$，再用 **GPT-5.2** 做语义最近检索，定位目标原子任务的首关节位姿：

$$\mathcal{P} = \operatorname{Extract}(\mathcal{D})$$

$$target\_pos = \operatorname{Search}(o_{i+1}^l,\; \mathcal{P},\; \mathcal{D})$$

随后由 GPT-5.2 生成过渡动作代码：

$$C_{i \rightarrow i+1} = \operatorname{GPT}(o_{i+1}^l,\; o_t^v,\; target\_qpos,\; curr\_qpos)$$

为抑制 LLM 幻觉，prompt 内提供**输出模板**（标注 `execute` 函数中可改部分 + 暴露平移/关节恢复接口），agent 只需决定末端移动方向与数值。**安全优先**：模板硬编码约束（"避免碰撞"），先检查夹爪是否需释放、附近是否有障碍 → 第一步即避障移到安全位姿 → 再用检索到的数据恢复目标关节位姿 → 恢复成功后交还 VLA。

### 模块 2：Transitional Action Insertion（过渡动作插入）

充当 VLA 与插件之间的**动作开关**。为每个原子任务预设最大运行时 $T$（实验取每原子任务平均演示时长）；VLA 到达推理终步时无论是否完成都强制终止（否则机械臂持续抖动）。过渡动作生成后重连 VLA、继续执行下一原子任务。两模块迭代直至整条长程任务结束。

> **方法定位**：Sci-VLA 只处理**原子任务之间的过渡**，不解决原子任务**内部**的精度问题——高精度子任务（如把 PCR 板插入插槽）的成功率仍取决于 base VLA 本身。

## 实验

- **数字孪生**：基于 MuJoCo 的生物实验室环境 **Autobio**，UR5e 机械臂；新增离子清洗机/旋涂机/热板等 3D 资产 + 移液器/离心管架/PCR 板等科学对象。
- **Base VLA**：扩散类 $\pi_0$、$\pi_{0.5}$ + 自回归类 fast（$\pi_0$-FAST）。每原子任务 100 条演示、微调 8–10 万步（科学操作任务用 4×H100）。

### "Cleaning Table" 基础验证（3 原子任务，各 20 试次）

| 方法 | 原子任务 1 | 原子任务 2 | 原子任务 3 |
|------|-----------|-----------|-----------|
| $\pi_0$ (finetuned) | 70% | 0% | 0% |
| **Sci-$\pi_0$** | 70% | **50%** ↑ | **20%** ↑ |
| $\pi_{0.5}$ (finetuned) | 65% | 0% | 0% |
| **Sci-$\pi_{0.5}$** | 60% | **15%** ↑ | **45%** ↑ |
| fast (finetuned) | 50% | 0% | 0% |
| **Sci-fast** | 50% | **25%** ↑ | **25%** ↑ |

裸 VLA 仅第一个原子任务可用（后续任务 **0%**，因 State Gap 卡死）；Sci-VLA 让后续任务起死回生。**平均每原子任务成功率提升约 42%**。$\pi_0$/$\pi_{0.5}$ 泛化优于 fast。

- **Atomic Task Coherence**：裸 $\pi_0$ 在第二原子任务起点持续抖动至超时；Sci-$\pi_0$ 全程保持完整连贯轨迹，即便某原子任务失败，过渡动作仍保证后续任务可执行。
- **6 个科学长程任务**（离心机/热循环仪场景，3/5/8 步）：Sci-VLA 在各序列长度上均提升成功率。基线在 A.4（关离心机盖）/ C.3（关热循环仪盖）异常高，因其初始态恰好衔接上一任务末态——反证 base VLA 对数据的强依赖。
- **真机迁移**：基于 Task C（操作热循环仪：C.1 开盖 → C.2 放 PCR 板）搭真实场景，微调 $\pi_0$。过渡轨迹"远离仪器盖 → 释放夹爪 → 移到下一任务起点"完整连贯，验证 sim-to-real 可迁移性。

## 与本知识库其他工作的关系

- **与 [[wiki/sources/agent-systems/2026-06-02 Agentic Robot (Yang 2025)]] 互补**：两者均**推理期用 LLM agent 编排 VLA**、不重训 base VLA，攻克长程任务。Agentic Robot 解决**子目标级误差/恢复**（VLM 验证器内省 + retry），Sci-VLA 解决**原子任务衔接的 State Gap**（生成过渡动作代码插桩）。详见 [[wiki/comparisons/Agentic VLA 系统对比]]。
- **与实验室自动化族（[[wiki/sources/lab-automation/2026-05-17 BioMARS (Qiu 2025)]] / ChemBot）呼应**：同属 AI4Science 机器人实验室，但 Sci-VLA 聚焦 VLA **执行层**的长程衔接而非高层实验规划。
- **与 [[wiki/sources/vla/2026-04-23 VLASH]] 对照**：都是推理期增强、不重训；VLASH 处理异步推理时延，Sci-VLA 处理原子任务间分布断裂。
