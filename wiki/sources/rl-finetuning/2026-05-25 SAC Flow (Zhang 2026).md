# SAC Flow: Sample-Efficient Reinforcement Learning of Flow-Based Policies via Velocity-Reparameterized Sequential Modeling

**Authors**: Yixian Zhang, Shu'ang Yu, Tonghe Zhang, Mo Guang, Haojia Hui, Kaiwen Long, Yu Wang, Chao Yu†, Wenbo Ding† (Tsinghua University, CMU, Li Auto, Shanghai AI Lab)
**Code**: https://github.com/Elessar123/SAC-FLOW

## TL;DR

Flow-based 策略与 off-policy RL（SAC）结合时，K-step Euler 积分的梯度爆炸/消失是核心障碍。本文的关键洞见是：**flow rollout 在代数上等价于 residual RNN**，因此可以用现代序列架构（GRU、Transformer）重参数化速度网络，从根本上稳定梯度。在此基础上配合 noise-augmented rollout 提供可解析 log-prob，实现端到端 SAC 训练，无需代理目标或策略蒸馏。

---

## 核心贡献

1. **Flow-as-RNN 视角**：证明 K 步 Euler 积分 $A_{t_{i+1}} = A_{t_i} + \Delta t_i\, v_\theta(t_i, A_{t_i}, s)$ 与 residual RNN 代数等价，梯度爆炸/消失机理因此可用 RNN 理论解释。
2. **两种稳定速度参数化**：
   - **Flow-G（GRU-gated）**：引入门控 $g_i = \text{Sig}(z_\theta(\cdot))$，速度写成 $v_\theta = g_i \odot (\hat{v}_\theta - A_{t_i})$，镜像 GRU update gate，自适应调节每步更新幅度。
   - **Flow-T（Transformer-decoded）**：速度 via Transformer Decoder，行动-时间 token $\Phi_{A_i}$ 经 L 层状态条件 cross-attention 精炼；对角 mask 保持 Markov 性，不做 causal 混合。
3. **Noise-augmented rollout**：在每步注入高斯噪声，使 joint path density $p_c(\mathcal{A}|s)$ 可解析，直接用作 SAC entropy 项，无需 normalizing flow 或 ELBO 近似。
4. **SAC Flow 算法**：Actor/Critic 损失直接对 $p_c$ 微分，支持 from-scratch 训练（密集奖励）和 offline-to-online 流水线（稀疏奖励，加近端正则化）。

## 严谨数学推导

### 符号定义

| 符号 | 含义 |
|------|------|
| $\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, p, r, \rho \rangle$ | 无限视野 MDP |
| $A_0 \sim \mathcal{N}(0, I_d)$ | 标准高斯基础分布 |
| $v_\theta(t, A_t, s)$ | 速度网络 |
| $0 = t_0 < \cdots < t_K = 1$ | Euler 积分时间步 |
| $\Delta t_i = t_{i+1} - t_i$ | 步长 |
| $\mu_\theta(\cdot|s)$ | flow 策略诱导分布 |

### 1. Flow Rollout 作为 Residual RNN

Euler 积分：

$$A_{t_{i+1}} = A_{t_i} + \Delta t_i\, v_\theta(t_i, A_{t_i}, s) =: A_{t_i} + f_\theta(t_i, A_{t_i}, s), \tag{5}$$

令 $f_\theta(\cdot) = \Delta t_i v_\theta(\cdot)$ 为 RNN cell，则 $A_{t_i}$ 为 hidden state，$(t_i, s)$ 为输入。Backprop through $K$ steps 等价于 deep RNN 反传，梯度范数乘积 $\prod_{i}\|\partial f_\theta/\partial A_{t_i}\|$ 在 $K$ 大时极易爆炸/消失。

### 2. Flow-G（GRU 门控速度）

$$A_{t_{i+1}} = A_{t_i} + \Delta t_i \bigl(g_i \odot (\hat{v}_\theta(t_i, A_{t_i}, s) - A_{t_i})\bigr), \quad g_i = \text{Sigmoid}(z_\theta(t_i, A_{t_i}, s)). \tag{6}$$

等价速度：$v_\theta = g_i \odot (\hat{v}_\theta - A_{t_i})$。门 $g_i \in (0,1)^d$ 自适应截断每步更新幅度，抑制梯度爆炸（类比 GRU update gate 对 $\|\nabla h_t\|$ 的控制）。

### 3. Flow-T（Transformer 解码速度）

嵌入：

$$\Phi_{A_i} = E_A(\phi_t(t_i),\, A_{t_i}), \quad \Phi_S = E_S(\phi_s(s)). \tag{7}$$

$L$ 层 cross-attention 精炼（对角 self-attention mask 保持 Markov 性）：

$$Y_i^{(l)} = \Phi_{A_i}^{(l-1)} + \text{Cross}_l\!\bigl(\text{LN}(\Phi_{A_i}^{(l-1)}),\; \text{context}=\text{LN}(\Phi_S)\bigr),\quad \Phi_{A_i}^{(l)} = Y_i^{(l)} + \text{FFN}_l(\text{LN}(Y_i^{(l)})). \tag{8}$$

最终解码速度：

$$A_{t_{i+1}} = A_{t_i} + \Delta t_i\, W_o\bigl(\text{LN}(\Phi_{A_i}^{(L)})\bigr). \tag{9}$$

Layer Norm 使每步残差有界，Transformer 深度可扩展且梯度稳定。

### 4. Noise-Augmented Rollout 与 SAC 目标

向量化噪声注入：

$$A_{t_{i+1}} = A_{t_i} + \Delta t_i\, v_\theta(t_i, A_{t_i}, s) + \sigma_i\,\varepsilon_i,\quad \varepsilon_i \sim \mathcal{N}(0, I),$$

使得 joint path $\mathcal{A} = (A_{t_0}, \ldots, A_{t_K})$ 服从 Gaussian product density $p_c(\mathcal{A}|s)$（闭式可解析）。

**Actor 损失**（from-scratch）：

$$L_\text{actor}(\theta) = \alpha \log p_c(\mathcal{A}^\theta|s_h) - Q_\psi(s_h, a_h^\theta),\quad a_h^\theta = \tanh(A_{t_K}^\theta). \tag{10}$$

**Critic 损失**（TD）：

$$L_\text{critic}(\psi) = \Bigl[Q_\psi(s_h, a_h) - \bigl(r_h + \gamma Q_{\bar\psi}(s_{h+1}, a_{h+1}) - \alpha\log p_c(\mathcal{A}_{h+1}|s_{h+1})\bigr)\Bigr]^2. \tag{11}$$

**Offline-to-Online**（稀疏奖励）加近端正则：

$$L_\text{actor}^o(\theta) = \alpha \log p_c(\mathcal{A}^\theta|s_h) - Q_\psi(s_h, a_h^\theta) + \beta\|a_h^\theta - a_h\|_2^2,\quad (s_h, a_h) \sim \mathcal{B}. \tag{12}$$

## 实验结果

| 场景                                                   | 方法                                    | 性能提升                           |
| ---------------------------------------------------- | ------------------------------------- | ------------------------------ |
| MuJoCo from-scratch（Hopper/Walker2D/HalfCheetah/Ant） | SAC Flow-G / Flow-T vs 强基线            | 最高 **+130%** cumulative return |
| OGBench offline-to-online manipulation               | SAC Flow vs Flow Q-Learning / Lv 2025 | 最高 **+60%** success rate       |

消融：噪声增强 rollout 和速度参数化各自独立贡献性能；Flow-T 在稀疏奖励任务（OGBench）优于 Flow-G。

## 关键洞见

- **Flow ≡ RNN** 的等价是本文所有结论的出发点：不仅是比喻，而是代数等价（Eq.5）。这解释了为什么先前工作必须绕过 flow rollout 的微分。
- **Noise-augmented rollout** 是实现 SAC 的关键工程技巧：不改变最终动作分布 $\mu_\theta(\cdot|s)$，但使中间路径的 log-prob 可解析。
- Flow-G 在参数量和速度上优于 Flow-T，但 Flow-T 在需要长程状态整合的稀疏奖励任务中更强。
