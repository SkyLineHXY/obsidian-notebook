# DPPO: Diffusion Policy Policy Optimization

> **论文**：arXiv:2409.00588v3（2024-12；作者列表含 Princeton、MIT、TRI、CMU）
> **作者**：Allen Z. Ren、Justin Lidard、Lars L. Ankile、Anthony Simeonov、Pulkit Agrawal、Anirudha Majumdar、Benjamin Burchfiel、Hongkai Dai、Max Simchowitz
> **项目主页**：https://diffusion-ppo.github.io

---

## 研究问题

预训练-微调已成为语言 / 视觉基础模型的主流范式，在机器人领域 **[[wiki/concepts/generative-models/Diffusion Policy|Diffusion Policy]]** 也成为标准策略参数化。但**如何用 RL 微调扩散策略**存在争议：
- 先前的 Psenka 等工作**推测策略梯度（PG）对扩散策略无效**，因为去噪步数放大了有效时域、动作方差过大。
- 已有微调方案多依赖加权回归或 Q-learning，在长时序操作任务上表现不稳定。

---

## 核心贡献

### 算法：DPPO
把**扩散去噪过程**本身建模为一个 MDP（称为 **Diffusion MDP**），再把它嵌入到**环境 MDP** 中，形成**两层 MDP**：

$$
\text{Outer MDP (Env)} \;\supset\; \text{Inner MDP (Denoising)}
$$

然后对这个两层 MDP 应用 **PPO** 风格的策略梯度：
1. 每个去噪步都有一个**可处理的高斯似然** $\log \pi(a^{k-1} \mid a^k, o)$
2. 通过两层 MDP 的 advantage 估计进行 clip 更新

### 三条关键设计决策

| 决策                            | 动机                                                 |
| ----------------------------- | -------------------------------------------------- |
| **PPO 作为外层优化器**               | 相比 REINFORCE / off-policy Q-learning 在长时序、高维动作下更稳定 |
| **只微调去噪过程的最后几步** 或改用 **DDIM** | 减少有效时域，提升样本效率与稳定性                                  |
| **修改噪声 schedule**             | 在微调阶段主动注入适度随机性，既利用扩散自带的结构化探索，又避免 value collapse    |

### 理论洞察：结构化探索
作者通过消融实验证明，与高斯策略或 GMM 相比，扩散策略在 RL 微调阶段**沿训练数据流形（manifold）进行探索**，因此：
- **探索更"有方向"**（不会乱撞障碍）
- **微调后的策略对扰动鲁棒**
- 体现出明显的 **sim-to-real** 迁移优势

---

## 实验结果

### 基准与平台
| 类别 | 具体任务 |
|------|----------|
| 长时序操作 | FurnitureBench（一桌多阶段装配） |
| 像素观测 | D4RL Gym / Robomimic（像素版） |
| 真实机械臂 | 从仿真到真实机器人的 **zero-shot 部署** |

### 主要结论
- 在所有扩散策略 RL 微调基线中，DPPO **综合性能与效率排名第一**
- 超越了基于 Q-learning、加权回归、demo-augmented RL 以及高斯 / GMM + PG 的对照方法
- 在长时序稀疏奖励任务（桌面装配）上的提升尤为显著
- 仿真训练的策略在真实硬件上 sim2real gap 很小

## 与其他 RL-for-Generative-Policy 方法的关系

| 方法                                                   | 策略类型              | 核心思想                         | 与 DPPO 关系                                         |
| ---------------------------------------------------- | ----------------- | ---------------------------- | ------------------------------------------------- |
| **DPPO**（本文）                                         | 扩散策略              | 两层 MDP + PPO                 | 扩散 RL 的 PG baseline                               |
| [[wiki/sources/rl-finetuning/2026-04-18 ReinFlow\|ReinFlow]]       | Flow Matching     | 注入可学习噪声把 ODE 变成 Markov 过程    | 思想相似，但把 DPPO 的 PG 适配到 Flow Matching；比 DPPO 快 60%+ |
| [[wiki/sources/rl-finetuning/2026-04-19 Flow Q-Learning\|FQL]]     | Flow Matching     | 蒸馏到一步策略，完全避免迭代 BPTT          | 离线 RL 路径，和 DPPO 思路正交                              |
| [[wiki/sources/vla-rl/2026-04-19 π0.6 RECAP\|π₀.₆ / RECAP]] | Flow Matching VLA | Advantage-conditioning 替代 PG | 认为 PPO 式方法难以 scale 到大 VLA，提出替代方案                  |
