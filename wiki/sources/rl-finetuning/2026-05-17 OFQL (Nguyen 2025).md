## 一句话摘要

将 Diffusion Q-Learning（DQL）重新表述为 Flow Matching 框架，并通过学习 **average velocity field** 实现训练和推理时的单步动作生成，无需辅助模型或蒸馏，在 D4RL 上超越 DQL 同时大幅降低运行时开销。

---

## 核心背景与动机

### 问题：DQL 的多步推理瓶颈

Diffusion Q-Learning（DQL）是 offline RL 中持续 SOTA 的方法，但有两个核心限制：

1. **多步去噪**：训练和推理都需要迭代去噪，推理延迟高
2. **单步直接失败**：直接将 DQL 压缩到 one-step 产生严重性能下降

已有的加速尝试（如蒸馏）需要额外训练阶段或辅助模型，增加了工程复杂度。

### 关键洞察

Flow Matching 的轨迹相比 DDPM 更直，理论上更适合单步近似。但标准 FM 的 **conditional velocity field** 仍然是路径依赖的（曲线 → 单步误差大）。

OFQL 发现：学习 **marginal average velocity field**（对所有条件路径取期望的速度场）可以绕过路径依赖，直接从噪声到干净动作做精确单步映射。

## 方法：OFQL

### 核心区别

|      | 标准 Flow Matching                             | OFQL                                      |
| ---- | -------------------------------------------- | ----------------------------------------- |
| 学习目标 | Conditional velocity: $u(x_t \mid x_0, x_1)$ | Marginal average velocity: $\bar{u}(x_t)$ |
| 推理   | 需要迭代 ODE 求解                                  | 单步映射 $x_0 \to x_1$                        |
| 路径   | 条件直线（但边缘弯曲）                                  | 边缘平均 → 直接映射                               |

### 训练目标

$$\mathcal{L}_{\text{OFQL}} = \mathbb{E}_{t, x_0, x_1}\left[ \| \bar{u}_\theta(x_t) - (x_1 - x_0) \|^2 \right]$$

其中 $x_t = (1-t)x_0 + t x_1$（线性插值），$x_0 \sim \mathcal{N}(0, I)$，$x_1 \sim \pi_{\text{data}}(\cdot \mid s)$。

这个 loss 直接最小化 velocity field 对"从噪声到数据"方向的期望估计误差，推理时只需一次前向：

$$a = x_0 + \bar{u}_\theta(x_0)$$

### Q-Learning 集成

沿用 DQL 的 Q-function 训练方式（TD3+BC 风格），将扩散策略部分替换为 OFQL 的单步流策略：

$$\pi^* = \arg\max_\pi \mathbb{E}[Q(s, a)] - \lambda \mathcal{L}_{\text{OFQL}}$$

无需多步 rollout 计算梯度 → 消除 DQL 的递归梯度更新问题。

## 实验结果

### D4RL 基准

- 在 D4RL 全套（HalfCheetah / Hopper / Walker / AntMaze）上超越 DQL 及其他扩散 baseline
- **训练时间**：相比 DQL 大幅缩短（消除递归梯度 + 单步采样）
- **推理延迟**：单步推理，比 DQL 多步推理降低数量级

### 消融分析

- 仅用 conditional velocity（而非 average velocity）→ 单步推理性能大幅下降，证实 average velocity field 是关键
- 去掉 Q-Learning 约束 → 退化为标准 BC 流策略
