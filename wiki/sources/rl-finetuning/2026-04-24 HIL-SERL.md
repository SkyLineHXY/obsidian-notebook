# HIL-SERL — Precise and Dexterous Robotic Manipulation via Human-in-the-Loop RL

[[Luo 等 - 2025 - Precise and Dexterous Robotic Manipulation via Human-in-the-Loop Reinforcement Learning]]

> Luo, J., Xu, C., Wu, J., & Levine, S. (2025). *Precise and Dexterous Robotic Manipulation via Human-in-the-Loop Reinforcement Learning.* UC Berkeley.

---

## 一句话摘要

[[wiki/entities/systems/HIL-SERL]] 是 UC Berkeley 提出的真实世界视觉 RL 系统，通过**人类在线纠错 + 离线演示 + 高效 off-policy RL** 的组合，在 1–2.5 小时内训练出成功率 100%、周期时间比 BC 快 1.8× 的灵巧操控策略，覆盖精密装配、双臂协调、动态操控等高难度任务。

---

## 核心问题与动机

真实世界 RL 的三大挑战：
1. **样本效率低**：高维图像输入的 RL 收敛慢
2. **奖励设计难**：复杂任务难以手动设计稠密奖励
3. **优化不稳定**：随机探索容易损坏设备

现有方法的局限：
- **BC/HG-DAgger**：依赖人类演示，缺乏自我纠错机制，无法超越演示质量
- **SERL（前作）**：仅用离线演示，不引入在线纠错，对高难任务不够
- **其他 RL 方法**（IBRL、Residual RL、DAPG）：严重依赖 BC 初始化质量

**核心洞察**：**人类在线纠错（corrections）** 而非仅演示（demonstrations），是解锁复杂任务的关键。

## 系统架构

HIL-SERL 由三个并行组件构成：

```
┌──────────────────────┐     policy params      ┌──────────────────────┐
│     Actor Process    │ ←──────────────────────  │    Learner Process   │
│  - 执行当前策略       │                          │  - RLPD 优化策略      │
│  - 支持 SpaceMouse   │ ──── interaction data ──→ │  - 均匀采样两缓冲区   │
│    人类介入          │                          └──────────────────────┘
└──────────────────────┘                                   ↑ ↑
         ↓ data                                     ┌──────┴─┴──────┐
    ┌────────┐                               demo buffer    RL buffer
    │环境模块  │（多相机、SpaceMouse、单/双臂）
    └────────┘
```

## 方法细节

### 3.1 核心 RL 算法：RLPD

基础算法为 **RLPD**（Reinforcement Learning with Prior Data）——SAC 变体，支持离线 prior data 与在线数据的混合训练。

**Q-function 损失**：

$$
\mathcal{L}_Q(\phi) = \mathbb{E}_{\mathbf{s},\mathbf{a},\mathbf{s}'} \left[ \left( Q_\phi(\mathbf{s},\mathbf{a}) - \left( r(\mathbf{s},\mathbf{a}) + \gamma \mathbb{E}_{\mathbf{a}' \sim \pi_\theta} \left[ Q_{\hat\phi}(\mathbf{s}', \mathbf{a}') \right] \right) \right)^2 \right] \tag{1}
$$

**策略损失**（SAC 熵正则）：

$$
\mathcal{L}_\pi(\theta) = -\mathbb{E}_\mathbf{s} \left[ \mathbb{E}_{\mathbf{a} \sim \pi_\theta(\mathbf{a})} \left[ Q_\phi(\mathbf{s},\mathbf{a}) \right] + \alpha \mathcal{H}(\pi_\theta(\cdot|\mathbf{s})) \right] \tag{2}
$$

每个 training step **均匀从 demo buffer 和 RL buffer 各采一半**，避免遗忘演示知识。

### 3.2 关键系统设计

| 设计要素           | 具体方案                                 | 作用              |
| -------------- | ------------------------------------ | --------------- |
| **视觉骨干**       | ResNet-10（ImageNet 预训练）提取图像特征        | 稳定优化、提升探索效率     |
| **奖励函数**       | 二分类器（200 正样本 + 1000 负样本训练，精度 >95%）   | 稀疏但无需手动设计       |
| **坐标系**        | 本体感知以末端执行器初始帧为参考（自我中心）               | 空间泛化，物体移动时策略仍有效 |
| **控制器**        | 精密任务用阻抗控制器；动态任务用 feedforward wrench  | 安全探索，保护设备       |
| **Gripper 控制** | 独立的 DQN Critic（离散动作：open/close/stay） | 简化混合连续-离散 MDP   |

**Gripper DQN 更新**：

$$
\mathcal{L}(\theta) = \mathbb{E}_{\mathbf{s},\mathbf{a},\mathbf{s}'} \left[ \left( r + \gamma Q_{\theta'}(\mathbf{s}', \operatorname{argmax}_{\mathbf{a}'} Q_\theta(\mathbf{s}', \mathbf{a}')) - Q_\theta(\mathbf{s},\mathbf{a}) \right)^2 \right] \tag{3}
$$

### 3.3 人类在环（HIL）流程

训练流程参考 [[wiki/concepts/imitation-learning/HG-DAgger]]（Kelly 等 2018），但关键区别是用**强化学习**而非监督学习优化纠错数据：

1. 策略自主 rollout，人类持 SpaceMouse 监视
2. 策略即将失败时，人类**随时介入**接管控制
3. 介入数据**同时写入 demo buffer 和 RL buffer**；策略的非介入转移仅写入 RL buffer
4. 训练初期介入频繁（长段示范），随策略提升逐渐减少（短段纠错）→ 介入率最终趋近 0%

**注意**：长段稀疏介入会导致 Q 值过估计，需避免。

## 实验结果

### 任务设置（13 个任务）

涵盖 4 类操控挑战：
- **精密接触操控**：RAM 插入、SSD 装配、USB 插拔、USB 卡扣
- **双臂协调**：仪表板装配、物体传递、正时皮带装配、IKEA 货架拼装
- **动态操控**：Jenga 抽木块、锅中翻面

### 核心性能对比（HIL-SERL vs HG-DAgger BC 基线）

| 任务 | 训练时间 (h) | BC 成功率 | HIL-SERL 成功率 | BC 周期 (s) | HIL-SERL 周期 (s) |
|------|-------------|-----------|----------------|-------------|------------------|
| RAM 插入 | 1.5 | 29% | **100%** (+245%) | 8.3 | **4.8** (1.7×) |
| USB 插拔 | 2.5 | 26% | **100%** (+285%) | 13.4 | **6.7** (2×) |
| 正时皮带 | 6.0 | 2% | **100%** (+4900%) | 9.1 | **7.2** (1.3×) |
| Jenga 抽块 | 1.25 | 8% | **100%** (+1150%) | — | — |
| **平均** | — | **49.7%** | **100%** (+101%) | **9.6** | **5.4** (1.8×) |

与其他方法对比（选取 3 个任务）：

| 方法 | RAM 插入 | 仪表板装配 | 物体翻面 | 平均 |
|------|---------|-----------|---------|------|

| HG-DAgger | 29 | 41 | 46 | 39 |
| IBRL | 75 | 0 | 95 | 57 |
| **HIL-SERL** | **100** | **100** | **100** | **100** |

## 策略行为分析

### 鲁棒性：Q-value "漏斗"机制

通过可视化 RAM 插入任务的状态访问热力图，论文揭示 RL 训练形成了**漏斗（funnel）结构**：
- 策略通过 DP 将关键状态与高 Q 值动作连接
- **Q-value 方差**作为"关键状态"指标：$\operatorname{Var}[Q(\mathbf{s},\mathbf{a})] = \mathbb{E}_{\epsilon \sim \mathcal{U}[-c,c]}[(Q(\mathbf{s},\mathbf{a}+\epsilon) - \mathbb{E}[Q(\mathbf{s},\mathbf{a}+\epsilon)])^2]$
- 漏斗区域内状态访问密集、Q 值高、Q 值方差大，说明策略学会了在此精确执行
- HG-DAgger 的状态分布更分散，漏斗不明显

### 两类策略行为

| 任务类型 | 代表任务 | 策略特征 | 标准差模式 |
|----------|----------|----------|-----------|
| **反应式闭环** | RAM 插入、仪表板装配 | 持续视觉伺服，实时纠错 | 初始高（~0.6），接近目标时快速下降 |
| **预测式开环** | Jenga 抽块、锅中翻面 | 精确 reflex 动作，一次性执行 | 全程接近 0，高度一致 |

## 与相关工作的关系

- [[wiki/concepts/imitation-learning/HG-DAgger]]：HIL-SERL 的介入机制类似 HG-DAgger，但用 RL 而非 SL 优化纠错数据；实验证明差距在复杂任务中极为显著
- **SERL**（前作，Luo 等 2024）：仅用离线演示的 off-policy RL，不含在线纠错；本文 HIL-SERL 在此基础上加入了 corrections 机制
- **RLPD**（Ball 等 2023）：HIL-SERL 的核心底层算法

---

## 局限性

- 未进行大范围随机化，泛化到非结构化环境能力待验证
- 长 horizon 任务的样本复杂度问题尚未解决（正时皮带需 6 小时）
- 人类介入需要在旁操作，不完全自主
