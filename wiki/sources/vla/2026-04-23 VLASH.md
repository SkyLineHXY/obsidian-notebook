# VLASH（Tang et al., 2025）

**标题**：VLASH: Real-Time VLAs via Future-State-Aware Asynchronous Inference  
**机构**：MIT / NVIDIA / Tsinghua University / UC Berkeley / UCSD / Caltech  
**项目主页**：https://github.com/mit-han-lab/vlash

---

## 核心问题：同步推理的三大痛点

当前 VLA（[[wiki/entities/models/π₀.₅]]、GR00T 等）采用**同步推理**范式：推理 → 执行 → 推理……

1. **动作停顿（Action Stall）**：推理期间机器人静止不动
2. **反应延迟（Reaction Latency）**：感知到环境变化后，至少要等完当前执行块才能响应
3. **演示视频加速**：为掩盖停顿，VLA 演示视频常被 5–10× 加速

**异步推理（Async Inference）** 允许推理与执行并行，消除停顿。但产生**预测-执行时间错配（Prediction-Execution Misalignment）**：

$$I_t^{\text{pred}} = [t,\ t+K) \quad \Rightarrow \quad I_t^{\text{exec}} = [t+\Delta,\ t+\Delta+K)$$

其中 $\Delta > 0$ 为推理延迟（步数）。预测时的状态 $s_t$ 与执行时 $s_{t+\Delta}$ 已不同，导致动作不稳定、性能下降。

---

## 核心方法：VLASH

**VLASH = 未来状态感知（Future-State Awareness）+ 时间偏移增强 + 共享观测高效微调 + 动作量化**

### 4.1 未来状态滚动（State Rollforward）

推理开始时，前一动作块的剩余动作 $a_t, a_{t+1}, \ldots, a_{t+\Delta-1}$ 已知，通过前向积分得到执行时状态：

$$s_{t+\Delta} = \text{rollforward}(s_t,\; a_t,\; a_{t+1},\; \ldots,\; a_{t+\Delta-1})$$

将 $(o_t,\ s_{t+\Delta})$ 而非 $(o_t,\ s_t)$ 输入 VLA，使预测动作块与执行时状态对齐。

> 类比人类：我们对世界的视觉感知有轻微延迟，但通过内在的肢体状态预测来补偿这一延迟。

### 4.2 时间偏移增强（Temporal-Offset Augmentation）

现有 VLA 微调时常忽略状态输入，仅依赖视觉。VLASH 在微调时随机采样偏移 $\delta \in \{0, \ldots, \Delta_{\max}\}$，构建训练样本 $(o_t,\ s_{t+\delta},\ A_{t+\delta})$：

- 同一图像 $o_t$ 对应不同未来状态 $s_{t+\delta}$，**强迫模型学会利用状态输入**
- 支持部署时不同 $\Delta$（不同硬件推理延迟各异）
- 无额外架构改动，直接集成到标准微调 pipeline

### 4.3 共享观测高效微调（Shared Observation Fine-tuning）

将 $N_\delta$ 个偏移分支打包进单次前向，减少重复编码观测 token：

$$[o_t,\; (s_t, A_t),\; (s_{t+1}, A_{t+1}),\; \ldots,\; (s_{t+\Delta_{\max}}, A_{t+\Delta_{\max}})]$$

使用**块稀疏自注意力**：
- 观测 token 互相可见（正常）
- 各偏移分支仅关注自身 + 共享观测，分支间隔离

对于 $\pi_{0.5}$（约 700 观测 token vs 50 状态-动作 token），打包 5 个偏移仅增加约 20% 序列长度，但等效训练数据量增大 5×，实现 **3.26× 训练速度提升**。

### 4.4 动作量化（Action Quantization）

类比 LLM 权重量化：将 $q$ 个连续细粒度动作合并为宏动作（macro-action）：

$$\hat{a}_i = a_{iq} + a_{iq+1} + \cdots + a_{(i+1)q-1}$$

每步执行更大幅度的运动，进一步压缩执行步数，提供可调速度-精度权衡。

## 实验结果

### LIBERO 仿真（π₀.₅，4 子基准）

| 方法 | 推理延迟 $\Delta$ | 平均成功率 | 加速 |
|------|----------------|-----------|-----|
| Sync（同步基线） | 0 | 96.8% | — |
| VLASH | 1 | 97.2% | **1.17×** |
| VLASH | 2 | 97.1% | **1.31×** |
| VLASH | 3 | 94.6% | **1.47×** |

### Kinetix 动态仿真（与 Naive Async / RTC 对比）

在推理延迟 $\Delta=4$ 步时：
- **VLASH**：81.7% 成功率
- Naive Async：51.2%（**VLASH 提升 30.5%**）
- RTC：随延迟增大急剧下降

### 真实机器人（Galaxea R1 Lite + LeRobot SO-101，3 任务）

| 配置 | 平均得分 | 完成时间 |
|------|---------|---------|
| Sync（同步） | 83% | 21.0s |
| Naive Async | 89.7% | — |
| **VLASH** | **94.0%** | **18.8s（1.12×）** |
| **VLASH（q=2 量化）** | 持平 | **2.03× 加速** |
| VLASH（q=3 量化） | −4.7% | 2.67× 加速 |

### 反应延迟（π₀.₅，RTX 5090）

| 推理方式 | 最大反应延迟 |
|---------|------------|
| 同步推理 | 530ms |
| VLASH 异步 | **30ms（17.4× 提升）** |

**里程碑**：首次演示 VLA（π₀.₅ + VLASH）与人类进行**乒乓球对打 rally**，实现高速反应 + 精准连续运动。
