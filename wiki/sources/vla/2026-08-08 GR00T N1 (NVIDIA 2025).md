# GR00T N1: An Open Foundation Model for Generalist Humanoid Robots

[[raw/assets/papers/VLA/NVIDIA 等 - 2025 - GR00T N1 An Open Foundation Model for Generalist Humanoid Robots.pdf]]

**作者**：NVIDIA GEAR Lab（研究负责人 Linxi "Jim" Fan、Yuke Zhu；核心贡献者 Scott Reed、Ruijie Zheng、Guanzhi Wang、Johan Bjorck、Joel Jang 等）
**arXiv**：[2503.14734](https://arxiv.org/abs/2503.14734)（v1 2025-03-18 / v2 2025-03-27）
**开源**：GitHub `NVIDIA/Isaac-GR00T`，checkpoint `GR00T-N1-2B`
**摄取日期**：2026-08-08


---

## 一句话摘要

GR00T N1 提出**双系统 VLA 架构**（VLM 推理 + DiT flow-matching 动作生成）与**数据金字塔**训练范式（人类视频 / 仿真轨迹 / 神经轨迹 / 真机遥操作），用 88 小时真机数据经合成放大后训出跨本体人形机器人基础模型，在真机上以 10% 数据逼近 Diffusion Policy 全量数据的表现。

## 模型架构

![[raw/sources/papers/VLA/NVIDIA 等 - 2025 - GR00T N1 An Open Foundation Model for Generalist Humanoid Robots/images/fig3_architecture.png]]
*Figure 3: GR00T N1 架构。Eagle-2 VLM（冻结）的视觉-语言 token 通过 cross-attention 注入 DiT；State/Action Encoder 与 Action Decoder 为具身相关模块；DiT 内 cross-attention 与 self-attention 交替，推理迭代 K 次。*

**总参数 2.2B**（VLM 1.34B）

| 组件 | 细节 |
|---|---|
| VLM（System 2） | Eagle-2，由 **SmolLM2** LLM + **SigLIP-2** 视觉编码器微调而来 |
| 图像编码 | 224×224 → pixel shuffle → 每帧 **64 个 image token** |
| 特征提取层 | LLM **第 12 层**（中间层优于最后一层：更快 **且** 成功率更高） |
| DiT（System 1） | cross-attention 与 self-attention **交替**堆叠（类 Flamingo / VIMA），adaLN 注入去噪步条件 |
| 跨本体适配 | 每本体独立 MLP：State Encoder / Action Encoder / Action Decoder |
| Action chunk | $H=16$ |
| 去噪 | forward Euler，$K=4$ 步 |
| 推理速度 | L40 + bf16，采样 16 步动作 **63.9 ms**；VLM ~10 Hz，动作模块 ~120 Hz |
| 训练 | 最多 1024×H100（NVIDIA OSMO + Ray）；预训练约 **50,000 H100 GPU·hours** |

**与 π₀ 的架构差异（论文自述）**：π₀ 用 mixture-of-experts 桥接 VLM 与动作生成，GR00T N1 用**简单 cross-attention**——理由是这样 VLM 与动作头的具体架构可以各自独立替换，灵活性更高。（后续四代反复更换 VLM 骨干，印证了这一设计动机。）

### Flow Matching 公式

$$A_t^{\tau} = \tau A_t + (1-\tau)\epsilon, \qquad \epsilon \sim \mathcal{N}(0,I)$$

$$\mathcal{L}_{\text{fm}}(\theta) = \mathbb{E}_\tau\Big[\big\|V_\theta(\varphi_t, A_t^\tau, q_t) - (\epsilon - A_t)\big\|^2\Big]$$

时间步采样 $p(\tau) = \mathrm{Beta}\big(\tfrac{s-\tau}{s}; 1.5, 1\big),\ s=0.999$；推理更新 $A_t^{\tau+1/K} = A_t^\tau + \tfrac{1}{K}V_\theta(\varphi_t, A_t^\tau, q_t)$。

完整推导见 [[wiki/analyses/GR00T 系列演进详细解析]] §8 与 [[wiki/analyses/Flow Matching 完整数学推导]]。

### 无动作标签数据的两条解法

**Latent Actions（LAPA）**：训练 VQ-VAE，编码器吃 $(x_t, x_{t+H})$ 输出潜动作 $z_t$，解码器由 $(z_t, x_t)$ 重建 $x_{t+H}$。训练后**只用编码器**当逆动力学模型，取**量化前的连续嵌入**作动作标签，当成独立的 "LAPA" 本体用同一 flow matching 损失训练。在所有异构数据上联合训练 VQ-VAE，使全部数据共享同一潜动作空间（Fig.4 显示"右臂左移"在 8 种本体含人类上语义一致）。

**IDM 伪标注**：在真机数据上训逆动力学模型，为神经轨迹打伪动作标签。低数据场景下 IDM 也只用低数据训练，以贴合真实约束。

**神经轨迹生成流水线**：在 88 小时真机数据上微调 image-to-video 模型（480P，81 帧，100 epoch）→ 用商用多模态 LLM 检测初始帧物体并组合出物理可行的 "pick {object} from {A} to {B}" 指令 → 生成 → 用 LLM 作 judge（降采样 8 帧）过滤不遵循指令的视频 → 重新 captioning。

## 实验结果

**仿真（每任务 100 demo）**

| 方法 | RoboCasa | DexMG | GR-1 | 平均 |
|---|---:|---:|---:|---:|
| BC-Transformer | 26.3% | 53.9% | 16.1% | 26.4% |
| Diffusion Policy | 25.6% | 56.1% | 32.7% | 33.4% |
| **GR00T-N1-2B** | **32.1%** | **66.5%** | **50.0%** | **45.0%** |

**真机 GR-1**

| 方法 | Pick-and-Place | Articulated | Industrial | Coordination | 平均 |
|---|---:|---:|---:|---:|---:|
| DP (10%) | 3.0% | 14.3% | 6.7% | 27.5% | 10.2% |
| DP (全量) | 36.0% | 38.6% | 61.0% | 62.5% | 46.4% |
| GR00T-N1 (10%) | 35.0% | 62.0% | 31.0% | 50.0% | 42.6% |
| **GR00T-N1 (全量)** | **82.0%** | **70.9%** | **70.0%** | **82.5%** | **76.8%** |

**核心结论**：GR00T-N1 用 10% 数据（42.6%）仅比 Diffusion Policy 全量（46.4%）低 3.8 个点。

**预训练 checkpoint 零样本真机**：双手协同交接 **76.6%**（11.5/15）；新物体放入未见容器 **73.3%**（11/15）。

**神经轨迹协同训练增益**（1:1 采样）：RoboCasa 30/100/300 demo 下 **+4.2% / +8.8% / +6.8%**；真机 GR-1 八任务平均 **+5.8%**。LAPA vs IDM：低数据（30）LAPA 略优，数据增多（100/300）IDM 反超且差距扩大。

**评测协议**：仿真 100 试，取最后 5 个 checkpoint 的最高分（每 500 步存一次），遵循 RoboCasa 协议；真机每任务 10 试，采用分段计分。

## 论文自陈局限（后三代的路线图）

§4.6 明确指出：当前仅覆盖**短程桌面操作**；未来需要 **long-horizon loco-manipulation**（需硬件、架构、语料共同进步）、**更强的 VL 骨干**（改善空间推理与语言理解）、以及**物理一致性更好的合成数据**。

对照后续：N1.5 补语言理解，N1.6 补 loco-manipulation 与多机身，N1.7 补数据源与推理骨干。
