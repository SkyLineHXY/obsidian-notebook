# π₀.₇: a Steerable Generalist Robotic Foundation Model with Emergent Capabilities

[[raw/sources/papers/VLA/Intelligence 等 - 2026 - $π_{0.7}$ a Steerable Generalist Robotic Foundation Model with Emergent Capabilities/Intelligence 等 - 2026 - $π_{0.7}$ a Steerable Generalist Robotic Foundation Model with Emergent Capabilities.md]]

**发表机构**：Physical Intelligence

## 一句话摘要

π₀.₇ 通过**多模态多样化 Prompt Conditioning**（subtask instructions + subgoal images + episode metadata + control mode）训练，使单一泛化模型开箱即用地媲美 RL 专家策略，并涌现出零样本跨机身迁移与组合任务泛化能力。

---

## 核心背景与动机

### 问题
VLA 领域长期存在的困境：泛化模型（generalist）性能往往不如针对单任务微调的专家模型（specialist）。数据集中混杂着不同质量、不同策略的数据，朴素训练导致模型对多模态数据"取平均"，产生次优动作。

### 核心洞察
借鉴图像/视频生成领域的 **prompt expansion** 思想：在训练时向模型提供丰富的上下文信息（不仅是"做什么"，还有"怎么做"），让模型能区分不同质量和策略的数据，从而：

1. 从混合质量数据（包括失败 episode、次优自主数据）中有效学习
2. 蒸馏 RL 专家能力至一个泛化模型
3. 在推理时通过 prompt 精确引导期望行为

## 模型架构

**总参数量：~5B**

| 组件 | 细节 |
|---|---|
| VLM 骨干 | Gemma3 4B（含 400M 视觉编码器）|
| 视觉编码器 | MEM-style 时空压缩，处理多视角 × 多历史帧，输出固定数量 token |
| Action Expert | 860M 参数 flow matching transformer，预测 50 步 action chunk |
| 注意力机制 | Block-causal masking：视觉 token 双向注意力；subgoal token 可额外 attend 观测；文本 causal 注意力 |
| 本体感觉 | history proprioceptive state 通过线性投影直接嵌入骨干（与 π₀.₆ 使用离散 token 不同）|
| 推理加速 | RTC（Real-time Chunking）训练期模拟 0–12 步延迟（最大 240ms @50Hz）|

**相比 π₀.₅ / π₀.₆ 的架构变化**：
- 引入 MEM 视频历史编码器（来自 [37] Torne 等 2026）
- 支持多视角 subgoal images 注入 context
- 本体感觉改用线性投影嵌入而非离散 token

## 多模态 Prompt 组成（核心创新）

π₀.₇ 的 prompt $\mathcal{C}_t$ 由四类信息构成，训练时各项随机 dropout，推理时可任意组合：

### A. Subtask Instructions（子任务指令）$\hat{\ell}_t$
- 在总任务指令 $\ell_t$（如"clean the kitchen"）基础上，额外提供当前语义子任务（如"open the fridge door"）
- 由 learned high-level policy（与 π₀.₇ 同架构）或人类实时提供
- 启用"语言 coaching"能力：人类逐步用语言指令引导机器人完成未见任务

### B. Subgoal Images（子目标图像）$\mathbf{g}_t$
- 多视角目标图像 $\mathbf{g}_t = [G_t^1, \ldots, G_t^n]$，描述当前子任务完成后的近未来场景
- 同时覆盖环境视角（整体布局）和腕部视角（末端执行器姿态），实现精细空间基础
- **推理时由 World Model 生成**：$\mathbf{g}^\star \sim p_\psi(\mathbf{g}^\star \mid \mathbf{o}_t, \hat{\ell}_t, m)$

**World Model 细节**：
- 基于 BAGEL（14B Mixture-of-Transformers，图像理解/编辑/生成预训练）微调
- 训练目标为 flow matching loss $\mathcal{L}_\text{CFM}$
- 训练数据混合：真实未来帧 + 非机器人 egocentric 视频 + web 视频
- 训练时 25% 样本注入 subgoal images；其中 30% 同时 dropout 子任务指令

### C. Episode Metadata（Episode 元信息）$m$
标注每个训练 episode 的客观属性，消解多模态数据的歧义：

| 元信息字段 | 内容 |
|---|---|
| Overall speed | episode 总时长（以 500 步粒度离散化）|
| Overall quality | 执行质量评分 1–5（5 最高）|
| Mistake | 是否存在操作失误（bool，由人工粗粒度标注）|

**推理时设置**：speed → 第 15 百分位历史 episode 长度；quality → 5；mistake → false

### D. Control Mode（控制模式）$c$
- $c \in \{\text{joint}, \text{ee}\}$，以文本标识区分 joint-space 和 end-effector 控制
- 训练数据同时包含两种模式，推理时按任务选择

### 完整 Prompt 示例
```
<Multi-view obs><Multi-view subgoals>
Task: peel vegetables. Subtask: pick up the peeler.
Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint.
<Proprioception>
```

## 推理流程

Algorithm 1 描述推理时序：

1. 初始化：high-level policy 生成首个 $\hat{\ell}$，world model 生成首帧 subgoal $\mathbf{g}^\star$
2. **异步刷新**：当 $\hat{\ell}$ 变化或距上次 subgoal 生成 $\Delta=4$ 秒后，异步更新 subgoal（不阻塞主控制循环）
3. **每 $\hat{H} \in \{15, 25\}$ 步**：调用 VLA 生成新的 50 步 action chunk（结合 RTC 处理推理延迟）
4. **Classifier-Free Guidance (CFG)**：对 episode metadata 应用 CFG，$\beta \in \{1.3, 1.7, 2.2\}$：

$$\nabla_\mathbf{a} \log \pi_\theta(\mathbf{a}_{t:t+H} \mid \mathbf{o}_t, \mathcal{C}_t) + \beta \left(\nabla_\mathbf{a} \log \pi_\theta(\mathbf{a}_{t:t+H} \mid \mathbf{o}_t, \mathcal{C}_t) - \nabla_\mathbf{a} \log \pi_\theta(\mathbf{a}_{t:t+H} \mid \mathbf{o}_t, \mathcal{C}_t^\text{uncond})\right)$$

## 训练数据组成

π₀.₇ 训练数据构成（significant departure from classic VLA pipelines）：

| 数据类型                  | 来源                              |
| --------------------- | ------------------------------- |
| 高质量遥操作演示              | 多种机器人平台 × 多任务 × 实验室/家庭环境        |
| **低质量演示（失败 episode）** | 人类遥操作中的错误操作片段                   |
| **自主执行数据**            | π₀.₆* RL 训练过程中的 rollout 数据（含失败） |
| 人工干预数据                | 人类在策略 rollout 中的介入数据            |
| 开源机器人数据集              | —                               |
| Egocentric 人类视频       | —                               |
| Web 非机器人数据            | 目标定位、VQA、视频字幕、text-only 预测      |

**关键设计**：自主数据（含 π₀.₆* 的 RL rollout）通过 episode metadata 标注质量，使模型能有效"蒸馏" RL 专家行为，而不被低质量数据拖累。

## 实验结果

### A. 开箱即用性能（Out-of-the-Box Dexterity）
- 在 espresso making、box building、laundry folding 等复杂灵巧任务上，**直接匹配 π₀.₆* RL 专家**的成功率，甚至在 laundry/box building 吞吐量上超过专家
- 比较基线 `π₀.₇(no metadata)` 和 `π₀.₇(no eval data)` 均明显弱于完整 π₀.₇，验证 metadata + 自主数据的双重必要性

### B. 指令跟随（Instruction Following）
- **4 个未见厨房 + 2 个未见卧室环境**：14 个场景 × 3-6 步指令序列，显著优于 π₀.₅ 和 π₀.₆
- **复杂参照指令**（"pick up the fruit on the largest plate"）：π₀.₇ 显著优于 prior models；加入 subgoal images 进一步提升
- **反数据集偏置任务**（Reverse Bussing、Reverse Fridge to Microwave）：π₀.₇ 能遵循反直觉指令，证明语言理解能力而非单纯模仿

### C. 零样本跨机身迁移（Cross-Embodiment Transfer）
- **简单重排任务**（Table Setting、Bag In Backpack）：π₀.₅/0.6/0.7 均表现良好
- **高形态差异任务**（static bimanual → single-arm UR5e）：π₀.₇ 显著优于 prior models
- **灵巧任务迁移**（laundry folding → 未见过该任务的 bimanual UR5e）：
  - π₀.₇ 85.6% task progress，80% success rate
  - 人类遥操作专家首次尝试：90.9% task progress，80.6% success rate
  - **π₀.₇ 匹配人类零样本跨机身表现**，同时自动发现适合目标机器人形态的新操作策略（vertical grasp vs. tilted approach）
- Subgoal image conditioning（world model 生成）在跨机身迁移中关键：世界模型能生成适合目标机器人形态的 subgoal，提示合理的抓取配置

### D. 组合任务泛化（Compositional Task Generalization）
- **短 horizon 新任务**：开箱即用（wiping headphones, spinning desk fan, pressing french press 等），无需额外训练数据
- **长 horizon 新任务（语言 Coaching）**：Loading/Unloading Air Fryer、Toasting a Bagel——用逐步语言指令引导机器人完成从未见过的任务
- **Coaching → 自主策略**：coaching 数据直接用于训练 high-level policy，使 π₀.₇ 自主执行新任务，性能匹配 live coaching

### E. 数据多样性 Scaling 分析
- 随数据量增加（top 30% → all data），`π₀.₇(with metadata)` 持续改进；`π₀.₇(without metadata)` 反而下降 → **metadata 是利用低质量数据的关键**
- 去除最高 task diversity 的 20% 数据后，泛化性能显著下降 → **任务多样性驱动组合泛化**
