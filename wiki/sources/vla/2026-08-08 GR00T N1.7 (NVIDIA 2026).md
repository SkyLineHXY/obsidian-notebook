## 一句话摘要

N1.7 换用 **Cosmos-Reason2-2B（Qwen3-VL 架构）** 骨干，采用**人机共享的相对末端执行器（relative EEF）动作空间**，并在 **20K 小时 EgoScale 人类第一视角视频**上预训练——官方口径是「性能与 N1.6 相当，但泛化与语言跟随更好」。同时补齐了 ONNX/TensorRT 全流程部署与全身控制（SONIC）。

## 相对 N1.6 的精确配置 diff

| 配置项 | N1.6 | N1.7 |
|---|---|---|
| 模型包命名空间 | `gr00t_n1d6` | `gr00t_n1d7` |
| VLM 骨干 | `nvidia/Eagle-Block2A-2B-v2`（vendored Eagle） | **`nvidia/Cosmos-Reason2-2B`**（Qwen3-VL 架构，**gated 仓库**） |
| transformers | 4.51.3 | 4.57.3 |
| `select_layer` | 16 | **12** |
| `tune_top_llm_layers` | 4 | **0**（VLM 回到全冻结） |
| `load_bf16` | true | **false** |
| state / action 维度 | 29 | **132** |
| `action_horizon` | 16 | **40** |
| DiT 扩散层数 | 32 | **16** |
| 数据集输入 | 单路径 | **多路径 + `ds_weights_alpha` 混合权重** |
| rollout CLI 标志 | `--action-horizon` | `--execution-horizon`（澄清每次策略调用实际执行几步） |
| 传输层 | — | 更强的 object-dtype ndarray 序列化、更干净的 socket 超时行为 |

动作头仍是 flow-matching DiT；VLM 依旧支持弹性分辨率与原生宽高比编码。

> ⚠️ **资料冲突提示**：HuggingFace 上的 N1.7 介绍博客称动作头为「32 层 DiT」，其 model card 还写着「SigLip2 视觉编码器 + T5 语言编码器」。前者与仓库 config（16 层）矛盾，后者明显沿用旧模板。**以仓库 config 与 README diff 为准。**

## 两个核心叙事

### 1. 统一的相对 EEF 动作空间

N1.7 采用**在机器人本体与人类本体之间共享**的相对末端执行器动作空间：动作表示为**相对当前位姿的增量**而非绝对目标。官方明确称这是**跨本体性能的关键因素**。

**为什么这是打通人类视频的前提**：人手与机械臂的绝对关节空间无法对齐，但"相对当前末端位姿移动多少"在两种本体上是 $SE(3)$ 中的同类量。N1.6 引入相对动作时动机还只是动作平滑，到 N1.7 它变成了**跨本体迁移的载体**。

### 2. 20K 小时 EgoScale 人类视频预训练

底层研究为 **EgoScale**（arXiv [2602.16710](https://arxiv.org/abs/2602.16710)，NVIDIA + UC Berkeley + University of Maryland）：

- 在 **20,854 小时**有动作标注的第一视角人类视频上训练 VLA，规模超既往工作 **20 倍**；
- 发现人类数据规模与验证损失之间的 **log-linear scaling law**；验证损失**强相关于下游真机性能**，从而把大规模人类数据确立为**可预测的监督源**；
- 两阶段迁移配方：**大规模人类预训练 → 轻量的人-机对齐 mid-training**；
- **22-DoF 灵巧手**上相对无预训练基线**平均成功率 +54%**，并可迁移到更低 DoF 的手；支持 one-shot 任务适配。
- 官方口径：从 1K 小时到 20K 小时，**平均任务完成度翻倍以上**——被称为机器人灵巧性方向的首个 scaling law。

## 工程与生态

- **部署**：全流程 **ONNX + TensorRT** 导出；覆盖 dGPU（CUDA 12.8 / Py3.12）、Jetson AGX Thor 与 DGX Spark（CUDA 13.0 / Py3.12）、Jetson Orin（CUDA 12.6 / Py3.10）。
- **全身控制 SONIC**：`UNITREE_G1_SONIC` tag 接 [GEAR-SONIC](https://github.com/NVlabs/GR00T-WholeBodyControl) 控制器。VLA 预测**紧凑的隐动作 token**，由学习到的全身控制器解码为含腿、臂、手的全身关节指令；单策略端到端产生语言条件下的协同操作 + 移动。注意 `UNITREE_G1` tag 只兼容 decoupled WBC，端到端 collect-finetune-deploy 仅支持 `UNITREE_G1_SONIC`。
- **LeRobot 集成**：通过 `groot` policy type 提供。参见 [[wiki/sources/frameworks/2026-04-19 LeRobot]]。
- **数据格式**：LeRobot v2 变体 + GR00T 专有的 `meta/modality.json`（描述 state/action/video 结构）。
- **checkpoint**：Base `GR00T-N1.7-3B`；微调版 LIBERO / DROID / SimplerEnv-Bridge / SimplerEnv-Fractal。
- **训练规模**（model card）：21.6M 数据点、13 个数据集，混合人类/机器人/仿真采集与人工/自动标注。

## 上手要点

- **准入**：`nvidia/Cosmos-Reason2-2B` 是 **gated 仓库**，必须先在 HF 申请权限并 `huggingface-cli login`，否则加载**任何** N1.7 checkpoint（含 base）都会 `GatedRepoError` / 401。
- **`--state_dropout_prob`**：model config 默认 0.8，finetune CLI 默认 0.2；官方脚本按套件覆写（LIBERO-Long 0.2 / SimplerEnv Bridge 0.8 / Fractal 0.5）。**强依赖本体感觉的任务应调低。**
- **评测方差**：图像增强非确定性带来 **5–6% 跑间方差**，单次结果不足以下结论。
- **环境**：`uv sync --python 3.12`；视频后端**仅支持 torchcodec**（需 FFmpeg 4–7，FFmpeg 8 不兼容），decord / pyav 已弃用；AV1 数据集需转 H.264。
