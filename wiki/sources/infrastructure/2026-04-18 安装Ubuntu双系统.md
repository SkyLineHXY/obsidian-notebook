# 安装 Ubuntu 双系统

> **原文**：[CSDN 博客 - 安装Ubuntu双系统](https://blog.csdn.net/qq_59001382/article/details/142951549)
> **作者**：[[qq_59001382]] | **发布**：2024-10-15

---

## 核心要点

### 实验环境
- 设备：天选5pro（2025 款）
- CPU：Intel Core i7-14700HX | 显卡：RTX 4060
- 原系统：Windows 11 家庭中文版，BIOS 模式为 **UEFI**，磁盘分区为 **GUID**

### 关键前置检查
1. **确认 BIOS 模式**：运行 `msinfo32` 查看是 UEFI 还是 MBR（影响后续引导配置）
2. **关闭 BitLocker 加密**：**必做**，否则装完后 Windows 无法正常进入

### 安装盘制作
- 工具：**Ventoy**（推荐，可多 ISO 共存于一个 U 盘）
- 镜像：Ubuntu 20.04.6 / 22.04.4 desktop amd64.iso（下载自华为云镜像）

### BIOS 关键设置（缺一不可）
| 设置项            | 目的          |
| -------------- | ----------- |
| 关闭显卡直连         | 避免安装时画面异常   |
| 关闭 Secure Boot | 允许非微软签名的引导  |
| 关闭 Intel RST   | 避免磁盘识别冲突    |
| U 盘设为首启动       | 从 U 盘引导安装程序 |

### 分区方案（推荐"其他选项"自定义）
1. 找到 Windows 下压缩出的空闲区域
2. 挂载点选 `/`（根分区）
3. **引导器安装位置**：选含有 `Windows Boot Manager` 的 EFI 分区 → 实现双引导共存

### 安装后 GRUB 配置
- 问题：新显卡（RTX 40 系）需要添加 `nomodeset` 才能正常进入 Ubuntu
- 修复方法：在 `/etc/default/grub` 中：
  ```
  GRUB_CMDLINE_LINUX_DEFAULT="quiet splash nomodeset"
  ```

### 卸载方式
用 **DiskGenius** 删除 Ubuntu 分区，并手动清理 EFI 目录中的 `ubuntu` 引导项。
