# Ubuntu 安装实时内核和显卡驱动

> **原文**：[CSDN 博客 - Ubuntu安装实时内核和显卡驱动](https://blog.csdn.net/qq_59001382/article/details/142938618)
> **作者**：[[qq_59001382]] | **发布**：2024-10-15

## 核心要点

### 基础环境
- 系统：[[wiki/entities/hardware/Ubuntu 20.04]]（20.04.6 LTS）
- 基础内核：Linux 5.15.0-122-generic（通过 `uname -a` 查看）

---

## 安装 PREEMPT_RT 实时内核

> 详见概念页：[[wiki/concepts/infrastructure/PREEMPT_RT实时内核]]

### 版本对应原则
内核版本与 RT 补丁必须**严格对应**：
- 内核：`linux-5.15.167.tar.gz`（来自 kernel.org）
- 补丁：`patch-5.15.167-rt79.patch.gz`（来自 kernel.org/pub/linux/kernel/projects/rt）

### 编译流程摘要
1. 解压内核，应用 RT 补丁：`gzip -cd patch.gz | patch -p1`
2. 安装依赖：`apt-get install autoconf bison build-essential dkms dwarves ...`
3. **menuconfig 关键设置**：

| 路径 | 设置 |
|------|------|
| General Setup > Timers > Timer tick | Full dynticks system |
| General Setup > Timers | 开启 High Resolution Timer |
| General Setup > Preemption Model | **Fully Preemptible Kernel (RT)** |
| Processor > Timer frequency | **1000 HZ** |

4. 编辑 `.config`，清空 `CONFIG_SYSTEM_TRUSTED_KEYS` 和 `CONFIG_SYSTEM_REVOCATION_KEYS`（避免签名错误）
5. 编译安装：`make -j$(nproc) deb-pkg` → `sudo dpkg -i ../*.deb`

## 安装实时内核下的 NVIDIA 显卡驱动

### 核心问题
标准 NVIDIA 安装程序会检测 RT 内核并**拒绝安装**，必须手动编译内核模块。

### 解决方案：自定义安装脚本
关键环境变量：
```bash
export IGNORE_PREEMPT_RT_PRESENCE=true
```
设置此变量后，NVIDIA 内核模块可在 RT 内核下正常编译（`make -j${CPUNUM} module`）。

### 步骤摘要
1. 禁用 nouveau 默认驱动（加入 `/etc/modprobe.d/blacklist.conf`）
2. 从 NVIDIA 官网下载对应版本的 `.run` 驱动文件（如 `NVIDIA-Linux-x86_64-535.183.01.run`）
3. 运行自定义 `install-nvidia.sh` 脚本：提取 `.run` → 设置环境变量 → 编译 `nvidia.ko` → 安装用户态库
4. 验证：`nvidia-smi`
