## 一句话摘要

ChemBot 是首个将 VLA 模型与双层记忆架构结合、用于化学实验室长时域自动化操作的闭环框架，通过 Skill-VLA 和 MCP 服务实现高成功率的多阶段化学实验执行。

---

## 核心背景与动机

### 问题：化学实验室 VLA 的长时域与经验遗忘

化学实验室任务具有多阶段（multi-step）、高精度、长时域的特性——如移液、离心、培养等操作需按严格协议顺序执行。现有 VLA 模型存在两个核心缺陷：

1. **长时域推理能力不足**：VLA 模型在 10+ 步骤的协议执行中容易丢失全局状态；
2. **无持久经验积累**：每次执行均从零开始，不能复用成功轨迹，导致低效的 trial-and-error。

### 关键洞察

将"策略规划（cognitive agent）"与"技能执行（Skill-VLA）"分层解耦，并引入双层记忆（working memory + episodic memory）来持久化成功轨迹，使 VLA 能从过去的成功经验中检索并复用操作策略。

## 方法：ChemBot 双层闭环框架

### 系统架构

```
High-Level Planner (LLM-based Cognitive Agent)
    ↓ 任务分解 → 子任务序列
Skill-VLA（progress-aware VLA 执行模型）
    ↓ 感知-动作循环（异步推理）
Collaborative Robot（协作机械臂）
```

### 双层记忆架构

| 记忆层                 | 作用       | 存储内容               |
| ------------------- | -------- | ------------------ |
| **Working Memory**  | 短期任务状态缓冲 | 当前任务进度、最近观测、子任务上下文 |
| **Episodic Memory** | 长期经验积累   | 成功轨迹摘要、可检索的操作策略    |

成功轨迹被压缩为可检索资产（retrievable assets），下次遇到相似任务时直接召回，跳过 trial-and-error。

### Skill-VLA：进度感知 VLA 执行器

Skill-VLA 是一个对当前任务进度有感知的 VLA 模型，输入 $o_t$（视觉观测）和进度条件 $p_t$（当前执行到第几步），输出动作 $a_t$：

$$\pi_{\text{Skill}}(a_t \mid o_t, p_t, \text{skill\_desc})$$

其中 $p_t$ 由高层规划器提供，帮助 VLA 定位在长时域协议中的位置。

### MCP 服务器与工具编排

采用 **Model Context Protocol (MCP)** 服务器管理子 agent 和外部工具的调用接口（如液体传感器读数、机械臂状态查询），避免工具调用混乱。

### 异步推理（Asynchronous Inference）

VLA 推理延迟可能导致轨迹不连续。ChemBot 引入基于未来状态预测的异步推理机制：

$$\hat{o}_{t+\Delta} = f_{\text{world}}(o_t, a_t)$$

在等待 VLA 输出期间，使用预测的未来状态维持动作连续性，缓解轨迹断裂（trajectory discontinuity）。

## 实验结果

- 在协作机器人（collaborative robot）上执行复杂多阶段化学实验任务；
- 相比现有 VLA 基线（无记忆、单层规划），ChemBot 在**操作安全性、精度和任务成功率**上全面提升；
- 双层记忆机制显著减少重复试错次数，长时域任务（>10 步）提升尤为明显。

## 新概念追踪

**首次出现，追踪中**：
- **Skill-VLA**：进度条件化的 VLA 执行器，将任务步骤进度 $p_t$ 作为额外条件输入；仅来源 38
- **Episodic Memory for Robot VLA**：将成功操作轨迹持久化为可检索资产、避免重复试错的长期记忆机制；仅来源 38
- **Trajectory Discontinuity（VLA 推理延迟问题）**：VLA 推理延迟导致的动作不连续性，以异步未来状态预测缓解；仅来源 38
