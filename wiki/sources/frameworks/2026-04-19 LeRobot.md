# LeRobot: HuggingFace 的端到端机器人学习库

> **项目**：huggingface/lerobot
> **主页**：https://github.com/huggingface/lerobot
> **论文**：ICLR 2026（Cadene 等，"LeRobot: An Open-Source Library for End-to-End Robot Learning"）
> **类型**：Apache-2.0 开源，PyTorch 原生

---

## 项目定位

LeRobot 的目标是**降低真实世界机器人学习的准入门槛**，把"模型 + 数据集 + 工具链"像 🤗 Transformers 做 NLP 那样**标准化**并放到 HuggingFace Hub 上托管。核心卖点：
- **硬件无关**：统一的 `Robot` 抽象类，低成本臂（SO-100）到人形（Unitree G1）通吃
- **标准数据格式 LeRobotDataset**：Parquet + MP4/图像，支持 Hub 流式加载与可视化
- **SOTA 策略开箱即用**：IL / RL / VLA 全覆盖
- **社区驱动**：Discord、X、中文教程（同济子豪兄）、hackathon

## 快速上手
```bash
pip install lerobot
lerobot-info
```

```python
from lerobot.robots.myrobot import MyRobot
robot = MyRobot(config=...); robot.connect()
obs = robot.get_observation()
action = model.select_action(obs)
robot.send_action(action)
```

```bash
lerobot-train --policy=act --dataset.repo_id=lerobot/aloha_mobile_cabinet
lerobot-eval --policy.path=lerobot/pi0_libero_finetuned --env.type=libero --env.task=libero_object
```

## 支持的策略矩阵

| 类别 | 模型 |
|------|------|
| **Imitation Learning** | [[wiki/concepts/imitation-learning/ACT\|ACT]]、[[wiki/concepts/generative-models/Diffusion Policy\|Diffusion]]、VQ-BeT、Multitask DiT Policy |
| **Reinforcement Learning** | HIL-SERL、TDMPC；QC-FQL（即将） |
| **VLA** | Pi0Fast、Pi0.5、GR00T N1.5、SmolVLA、XVLA |

值得注意的交叉：
- LeRobot 将 **Diffusion Policy** 作为官方 IL 基线，直接对应 [[wiki/concepts/generative-models/Diffusion Policy]]
- **Pi0.5** 是 [[wiki/sources/vla-rl/2026-04-19 π0.6 RECAP|π₀.₆]] 的前代
- RL 模块提到 **QC-FQL**（与 [[wiki/sources/rl-finetuning/2026-04-19 Flow Q-Learning|FQL]] 同系列）

## 支持硬件
- **已原生集成**：SO100、LeKiwi、Koch、HopeJR、OMX、EarthRover、Reachy 2、Unitree G1、OpenARM，以及手柄、键盘、手机作为遥操作设备
- **可扩展**：实现 `Robot` 接口即可接入自定义硬件
- **仿真评估**：LIBERO、MetaWorld 等标准基准

---

## LeRobotDataset 标准

解决机器人数据碎片化问题：
- **同步 MP4 视频（视觉） + Parquet 表（状态/动作）**
- HuggingFace Hub 上已有数千个公开数据集
- 工具链：删除 episode、按比例/索引切分、合并数据集、增删特征列

```python
from lerobot.datasets.lerobot_dataset import LeRobotDataset
dataset = LeRobotDataset("lerobot/aloha_mobile_cabinet")
print(dataset[0]["action"].shape)
```

## 对 polymetis 路线的替代定位

本仓库在 knowledge base 中具有**工程方法论转折**的意义：
- [[wiki/sources/imitation-learning/2026-04-18 复现Diffusion-policy模型|复现 Diffusion Policy]] 的路径依赖 polymetis + libfranka + PREEMPT_RT，是**重工程、Franka 专用**的栈
- LeRobot 代表**轻量、硬件无关、数据集中心**的新范式
- 这正是 [[wiki/overview|overview.md]] Open Question #1 提到的"polymetis 是否有更现代的替代方案"的**直接答案**
