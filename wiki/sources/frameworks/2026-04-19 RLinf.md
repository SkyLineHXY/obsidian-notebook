# RLinf: Reinforcement Learning Infrastructure for Embodied and Agentic AI

**GitHub**：https://github.com/RLinf/RLinf  
**类型**：开源 RL 训练基础设施  
**定位**：具身 AI 与智能体 AI 的通用 RL 训练后端，"inf" 同时代表 Infrastructure 与 Infinite

---

## 核心定位

RLinf 是一个**灵活、可扩展**的开源 RL 基础设施，设计目标是屏蔽分布式编程的复杂性，让用户无需修改代码即可将 RL 训练扩展到大规模 GPU 集群。其混合执行模式（Hybrid Execution Mode）相比现有框架在具身 RL 场景下可达到 **2.434× 吞吐量**提升。

## 后端架构

| 模式    | 组合                                 | 适用场景         |
| ----- | ---------------------------------- | ------------ |
| 快速原型  | FSDP + HuggingFace / SGLang / vLLM | 新模型/算法适配、初学者 |
| 大规模训练 | Megatron + SGLang / vLLM           | 极致性能、专家用户    |

## 支持的算法

**在线 RL**：PPO、GRPO、SAC、DAPO、Reinforce++、CrossQ、RLPD、SAC-Flow  
**离线 RL**：IQL（D4RL）、[[wiki/concepts/rl/RECAP]]（离线 Advantage-conditioned 策略优化）  
**SFT / 模仿**：Full-param SFT、LoRA SFT、VLM SFT、[[DAgger]]、[[HG-DAgger]]  
**扩散策略 RL**：DSRL（在潜噪声空间训练轻量 SAC Agent 引导 π₀）

## 支持的模型

**VLA**：[[wiki/concepts/vla/Vision-Language-Action 模型|π₀]]、π₀.₅、OpenVLA、OpenVLA-OFT、GR00T、LingBot-VLA、Dexbotic、[[wiki/entities/frameworks/StarVLA]]  
**VLM**：Qwen2.5-VL、Qwen3-VL  
**世界模型**：OpenSora、Wan  
**自定义**：MLP-Policy、CNN-Policy

## 支持的仿真环境

ManiSkill、LIBERO / LIBERO-Pro / LIBERO-Plus[[RoboTwin]]]、RoboVerse、BEHAVIOR、MetaWorld、IsaacLab、CALVIN、RoboCasa、EmbodiChain、Franka-Sim

## 真实世界 RL

Franka 机械臂 + Intel RealSense / Stereolabs ZED + Robotiq 2F-85/2F-140 夹爪、XSquare Turtle2 双臂机器人

## 智能体 AI（Agentic AI）

单智能体：SearchR1、rStar2、Online Coder、Math Reasoning RL  
多智能体：WideSeek-R1（WideSeek-R1: Width Scaling for Broad Information Seeking via MARL）

## 重要近期更新（截至 2026-04）
