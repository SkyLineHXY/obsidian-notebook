# π₀.₇

**π₀.₇**（发音：pi zero point seven）是 Physical Intelligence 于 2026 年发布的第四代机器人 VLA 基础模型，也是截至本知识库记录时 π 系列的最新版本。

**项目页面**：https://pi.website/pi07  
**来源**：[[wiki/sources/vla/2026-04-29 π₀.₇]]

---

## 定位与核心目标

π₀.₇ 的核心目标是让**单一泛化模型**在不经任何任务特定微调的情况下，达到甚至超越 RL 微调专家模型（如 π₀.₆*）的性能水平。其设计哲学来自图像/视频生成领域的 prompt expansion 思想：通过在训练时向模型提供丰富的多模态上下文信息，使模型能区分不同质量和策略的数据，从而在推理时通过 prompt 精确引导期望行为。

---

## 架构参数

| 组件 | 规模 | 初始化 |
|---|---|---|
| VLM 骨干（含视觉编码器） | 4B（含 400M 视觉编码器） | Gemma3 4B |
| Flow Matching Action Expert | 860M | 随机初始化 |
| **总参数** | **~5B** | — |

**架构特征**：
- MEM-style 视频历史编码器（时空压缩，多历史帧→固定 token 数）
- Block-causal masking（视觉/subgoal token 双向；文本 causal）
- 本体感觉通过线性投影嵌入（vs. π₀.₆ 的离散 token 方式）
- RTC（Real-time Chunking）模拟延迟训练，最大 240ms @50Hz

---

## 核心创新：多模态 Diverse Prompt Conditioning

π₀.₇ 将训练 prompt $\mathcal{C}_t$ 扩展为四种模态（均支持随机 dropout，推理时可任意子集组合）：
1. **Subtask Instructions** $\hat{\ell}_t$：语义子任务文本（如"open the fridge door"），由 high-level policy 或人类提供
2. **Subgoal Images** $\mathbf{g}_t$：多视角近未来目标图像，由轻量级 World Model（BAGEL 初始化）异步生成
3. **Episode Metadata** $m$：speed（离散化 episode 时长）、quality（1-5 分）、mistake（bool）
4. **Control Mode** $c$：$\{\text{joint}, \text{ee}\}$ 控制模式标识

**推理时 Metadata 设置**：speed → 15th percentile、quality → 5、mistake → false  
**CFG 应用**：对 metadata 使用 Classifier-Free Guidance（$\beta \in \{1.3, 1.7, 2.2\}$）引导高性能动作

## 涌现能力（Emergent Capabilities）

### 1. 开箱即用灵巧操作
匹配 RL 微调专家 π₀.₆* 在 espresso making / box building / laundry folding 等任务的成功率，部分任务吞吐量甚至超过专家。

### 2. 复杂语言指令跟随
- 4 未见厨房 + 2 未见卧室：高指令跟随成功率
- 复杂参照指令（"pick up the fruit on the largest plate"）显著优于前代
- 反数据集偏置指令（Reverse Bussing）：证明真正的语言理解而非行为克隆

### 3. 零样本跨机身迁移
在从未采集该任务数据的目标机器人（bimanual UR5e）上完成 laundry folding：
- **85.6% task progress，80% success rate**
- 对比专家遥操作首次尝试：90.9% / 80.6%
- 自动发现适合目标机器人形态的新操作策略（vertical grasp vs. tilted approach）

### 4. 组合任务泛化 + Language Coaching
- 短 horizon 新任务开箱完成（wiping, spinning, scooping）
- 长 horizon 新任务通过逐步语言 coaching（Air Fryer / Toaster 任务）
- Coaching episodes → 训练 high-level policy → 全自主执行新任务
