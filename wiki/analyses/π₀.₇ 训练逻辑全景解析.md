# π₀.₇ 训练逻辑全景解析

> **问题**：π₀.₇ 中，整体训练逻辑是什么？VLA 骨干的 CFM 损失如何与世界模型（World Model）和高层策略（High-Level Policy）相结合？

**关联页面**：[[wiki/sources/2026-04-29 π₀.₇]] | [[wiki/entities/π₀.₇]] | [[wiki/concepts/Flow Matching]] | [[wiki/concepts/RECAP]]

---

## 1. 核心结论：三个独立模型，推理时协同

π₀.₇ **不是单一端到端训练的模型**，而是三个独立训练的组件在推理时通过 Prompt 机制组合工作：

```
推理时序（Algorithm 1）
─────────────────────────────────────────────────────
High-Level Policy ──→ 子任务指令 ℓ̂_t
        │
        ▼
World Model ──────→ 子目标图像 g*_t  （异步生成，每 4 秒或 ℓ̂ 变化时刷新）
        │
        ▼
VLA (π_θ) ────────→ action chunk a_{t:t+H}  （每 Ĥ 步调用一次，含 RTC 延迟补偿）
─────────────────────────────────────────────────────
```

**三个模型各自使用独立损失训练，不存在联合端到端梯度传播。** "结合"发生在推理时的 Prompt 组装阶段，以及训练数据的构建阶段。

## 2. VLA（π_θ）的训练逻辑

### 2.1 整体目标函数

VLA 的训练目标为条件对数似然的近似极大化：

$$\max_{\theta}\; \mathbb{E}_{\mathcal{D}}\!\left[\log \pi_{\theta}\!\left(\mathbf{a}_{t:t+H} \mid \mathbf{o}_{t-T:t},\, \mathcal{C}_t\right)\right] \tag{1}$$

- $\mathbf{a}_{t:t+H}$：长度为 $H=50$ 的 action chunk
- $\mathbf{o}_{t-T:t}$：历史观测（多视角图像 + 本体感觉），经 MEM 视觉编码器压缩
- $\mathcal{C}_t$：多模态 Prompt，见第 3 节

### 2.2 两级损失分离（Knowledge Insulation，KI）

VLA 内部由两个子网络构成，**梯度完全隔离**：

```
输入 Prompt C_t + 观测 o_{t-T:t}
           │
           ▼
┌──────────────────────────────────────────┐
│   VLM 骨干（Gemma3 4B，含 MEM 视觉编码器）│
│                                          │
│   监督信号：FAST tokens（离散化 action）  │
│   损失函数：离散 Cross-Entropy            │
│   梯度范围：仅在 VLM 内部传播             │
└──────────────────────────────────────────┘
           │
           │  激活值（单向流动，不反传梯度！）
           ▼
┌──────────────────────────────────────────┐
│   Action Expert（860M Flow Matching      │
│   Transformer）                          │
│                                          │
│   监督信号：连续 action chunk a_{t:t+H}    │
│   损失函数：CFM 流匹配损失 L_CFM         │
│   梯度范围：仅在 Action Expert 内部传播  │
└──────────────────────────────────────────┘
```

**设计动机**：
- VLM 骨干拥有大规模预训练的语言/视觉表征；CFM 损失是对数似然的近似下界，不稳定；KI 保护 VLM 只接受稳定的离散 CE 训练
- Action Expert 通过 **双向注意力** attend 到 VLM 所有位置的激活值，获得语义和视觉上下文
- 50 个 action token 之间互相双向注意力；用 adaptive RMSNorm 注入流匹配时间步 $\tau$

### 2.3 CFM 损失的数学形式

设目标 action chunk 为 $\mathbf{a}^* = \mathbf{a}_{t:t+H} \in \mathbb{R}^{50 \times d_a}$，流匹配时间步 $\tau \sim \mathcal{U}[0,1]$，噪声 $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$。

**线性插值路径**（Rectified Flow 风格）：

$$\mathbf{a}_\tau = (1 - \tau)\,\boldsymbol{\epsilon} + \tau\,\mathbf{a}^*$$

**目标向量场**（恒为常数方向）：

$$u_\tau(\mathbf{a}_\tau \mid \mathbf{a}^*) = \mathbf{a}^* - \boldsymbol{\epsilon}$$

**CFM 训练损失**（Action Expert 的参数化向量场 $v_\theta$）：

$$\mathcal{L}_\mathrm{CFM} = \mathbb{E}_{\tau,\,\mathbf{a}^*,\,\boldsymbol{\epsilon}}\!\left[\left\|v_\theta\!\left(\mathbf{a}_\tau,\,\tau \;\middle|\; \text{VLM 激活}\right) - \left(\mathbf{a}^* - \boldsymbol{\epsilon}\right)\right\|^2\right]$$

**推理时**：从 $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0},\mathbf{I})$ 出发，用 5 步 ODE 积分生成 $\mathbf{a}^*$：

$$\mathbf{a}_{\tau + \Delta\tau} = \mathbf{a}_\tau + \Delta\tau \cdot v_\theta\!\left(\mathbf{a}_\tau,\,\tau \mid \text{VLM 激活}\right)$$

## 3. 多模态 Prompt $\mathcal{C}_t$ 的构成与 Dropout 方案

$\mathcal{C}_t$ 由四类信息构成，训练时各项独立 dropout，推理时可任意子集组合：

| Prompt 组件        | 符号                                       | 来源                     | 训练 Dropout                |
| ---------------- | ---------------------------------------- | ---------------------- | ------------------------- |
| 总任务指令            | $\ell_t$                                 | 人工标注                   | 无 dropout                 |
| 子任务指令            | $\hat{\ell}_t$                           | High-Level Policy / 人类 | 含 subgoal 时额外 30% dropout |
| 子目标图像            | $\mathbf{g}_t = [G_t^1,\ldots,G_t^n]$    | World Model 生成 / 真实未来帧 | 仅 25% 样本含此项               |
| Episode Metadata | $m = \{\text{speed, quality, mistake}\}$ | 人工粗粒度标注                | 整体 15%，各字段额外 5%           |
| 控制模式             | $c \in \{\text{joint},\,\text{ee}\}$     | 数据标注                   | 无 dropout                 |

**完整 Prompt 示例**：

```
<Multi-view obs> <Multi-view subgoals>
Task: peel vegetables. Subtask: pick up the peeler.
Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint.
<Proprioception>
```

**Dropout 的双重作用**：
1. 使模型在任意 prompt 子集下均可工作（推理灵活性）
2. 为 Classifier-Free Guidance 提供训练基础（unconditioned 分支）

## 4. World Model（$g_\psi$）的训练

### 4.1 独立 CFM 训练目标

World Model 完全独立训练，**与 VLA 不共享梯度**：

$$\max_{\psi}\; \mathbb{E}_{\mathcal{D}_g}\!\left[\mathcal{L}_\mathrm{CFM}\!\left(\mathbf{g}_t^\star,\; g_\psi(\mathbf{o}_t,\,\hat{\ell}_t,\,m)\right)\right] \tag{2}$$

其中：
- $\mathbf{g}_t^\star = \mathbf{o}_{t_\mathrm{end}}$：训练片段末尾帧（ground truth subgoal 图像）
- $\mathbf{o}_t$：当前多视角观测（前方 + 两个腕部摄像头，共 3 路）
- $\hat{\ell}_t$：高质量人工子任务标注（标注质量对 subgoal 质量影响显著）
- $m$：episode metadata（speed / quality / mistake）
- $\mathcal{D}_g$：具有高质量子任务标注的数据子集

### 4.2 架构与初始化

| 组件        | 细节                                                                 |
| --------- | ------------------------------------------------------------------ |
| 初始化       | BAGEL（14B Mixture-of-Transformers，图像理解/编辑/生成预训练）                   |
| 图像处理（双路径） | ViT 路径：语义理解 → 7B LLM 骨干；VAE 路径：细粒度像素细节 → 7B 生成骨干                   |
| ViT 输入分辨率 | 448 × 336（patch size 14）                                           |
| VAE 输入分辨率 | 512 × 384（含目标图像，patch size 16）                                     |
| 每个训练样本    | 3 份当前帧拷贝（ViT 编码 + VAE 编码 + 含噪目标 VAE 编码），各自 block-bidirectional 注意力 |
| 训练数据混合    | 机器人片段 + egocentric 人类视频 + 开源图像编辑数据集 + 开源视频数据集                      |

### 4.3 推理时的异步调用（与 VLA 的耦合方式）

```
触发条件：子任务指令 ℓ̂ 发生变化  OR  距上次生成 Δ = 4 秒已过
操作：非阻塞异步调用 World Model
      g* ~ p_ψ(g* | o_t, ℓ̂_t, m)
      VLA 继续使用上一帧 g* 执行，直到新 g* 就绪
推理开销：4×H100 + 8-bit 量化 + SageAttention → 25 步去噪约 1.25 秒
```

**关键设计——训练时的 train-test 分布对齐**：

在 VLA 的 25% 含 subgoal 样本中：
- **0.25 概率**：使用 segment 末尾真实帧（与 World Model 训练目标一致）
- **0.75 概率**：均匀采样 0–4 秒内的未来真实帧
- **额外**：用离线预生成的 World Model 输出图像替换真实帧

这是因为训练时与测试时的 subgoal 来源不同（真实帧 vs 生成帧），必须在训练中混入生成图像以弥合分布差距。

## 5. High-Level Policy 的训练

### 5.1 架构与目标

High-Level Policy 与 VLA 共享**完全相同的架构**（Gemma3 4B 骨干），但任务不同：

```
输入：历史观测 o_{t-T:t}  +  总任务指令 ℓ  +  历史子任务指令序列
输出：当前子任务文本指令 ℓ̂_t
损失：离散 Cross-Entropy（文本 token 序列预测）
```

### 5.2 两类训练数据来源

**来源 A（常规轨迹标注）**：
- 对人工遥操作轨迹片段进行精细子任务语言标注
- 标注质量直接决定 World Model 和 High-Level Policy 的效果

**来源 B（Language Coaching 蒸馏）**：
```
Step 1：人类用逐步语言指令 coach π₀.₇ 完成全新任务
         ("open the air fryer" → "place sweet potato in basket" → ...)
Step 2：Coaching 过程中人类的指令时序 → 作为监督信号
Step 3：Fine-tune High-Level Policy → 使其能自主复现指令规划
Step 4：High-Level Policy 驱动 π₀.₇ 全自主执行新任务
```

这是 π₀.₇ 涌现的"组合任务泛化"能力的工程实现路径。

### 5.3 与 VLA 的解耦设计

High-Level Policy 运行在**语义层面**（数秒粒度的子任务规划），与 VLA 的低层动作控制（50Hz）完全解耦：
- 子任务指令刷新频率：每当任务阶段切换时
- Action chunk 执行步长：$\hat{H} \in \{15, 25\}$ 步
- 两者通过 Prompt 的 $\hat{\ell}_t$ 字段异步通信

## 6. 推理时：Classifier-Free Guidance（CFG）

由于 Episode Metadata $m$ 在训练时以 15% 概率整体 dropout（等价于训练了 unconditional 分支），推理时可对 metadata 施加 CFG，在每个 flow 去噪步骤内执行：

$$\nabla_{\mathbf{a}} \log \pi_{\theta}\!\left(\mathbf{a} \mid \mathbf{o}_t, \mathcal{C}_t\right) + \beta \left[\nabla_{\mathbf{a}} \log \pi_{\theta}\!\left(\mathbf{a} \mid \mathbf{o}_t, \mathcal{C}_t\right) - \nabla_{\mathbf{a}} \log \pi_{\theta}\!\left(\mathbf{a} \mid \mathbf{o}_t, \mathcal{C}_t^{\mathrm{uncond}}\right)\right] \tag{3}$$

其中 $\beta \in \{1.3,\, 1.7,\, 2.2\}$，$\mathcal{C}_t^{\mathrm{uncond}}$ 为 metadata 被 dropout 的 prompt 版本。

**物理意义**：将 action 分布向"高质量、无失误、快速执行"的模式推移，相当于在推理时**放大 RL 专家特征**，而不需要真正做 RL 微调。

**实现技巧（论文 Appendix B）**：正向（conditioned）和反向（unconditioned）序列通过 attention mask 构建"attention tree"并行打包为同一序列，单次 forward 同时计算两个分支，无需两次 forward。World Model 的 CFG 更复杂（3 个 CFG 分组：图像/文本/联合），用类似方案实现。

## 7. 三个训练目标的完整对比

| 模型                | 损失函数                                | 监督信号                                                    | 数据来源                     | 梯度边界                           |
| ----------------- | ----------------------------------- | ------------------------------------------------------- | ------------------------ | ------------------------------ |
| VLM 骨干            | 离散 Cross-Entropy                    | FAST tokens（action 的离散化）                                | VLA 全量训练集                | 仅在 VLM 内                       |
| Action Expert     | $\mathcal{L}_\mathrm{CFM}$（连续流匹配）   | 连续 action chunk $\mathbf{a}^*$                          | VLA 全量训练集                | 仅在 Action Expert 内；**不流回 VLM** |
| World Model       | $\mathcal{L}_\mathrm{CFM}$（图像生成流匹配） | 片段末帧 $\mathbf{g}_t^\star = \mathbf{o}_{t_\mathrm{end}}$ | 高质量标注子集 + web 数据         | 完全独立于 VLA                      |
| High-Level Policy | 离散 Cross-Entropy                    | 子任务文本 token $\hat{\ell}_t$                              | 轨迹标注 + coaching episodes | 完全独立于 VLA                      |

## 8. 各组件的"结合"方式汇总

三个模型虽然独立训练，但通过以下机制实现功能整合：

### 8.1 训练阶段的结合（数据构建层面）

```
VLA 训练数据中的 Subgoal 图像来源：
├── 75% 样本：无 subgoal（纯语言 + metadata prompt）
└── 25% 样本：
    ├── 真实未来帧（直接从轨迹采样）
    └── World Model 离线生成的 subgoal 图像（分布对齐）

π₀.₆* RL rollout 数据 → 以 episode metadata 标注 → 进入 VLA 训练集
    ↑ 这是 VLA "蒸馏"RL 专家能力的机制，不是联合 loss
```

### 8.2 推理阶段的结合（Prompt 组装层面）

```
t=0：High-Level Policy 生成首个 ℓ̂₀
     World Model 生成首帧 g*₀
     C₀ = {ℓ, ℓ̂₀, g*₀, m=(speed_15th, quality=5, mistake=false), c}

每个 tick：
  if ℓ̂ changed or 4s elapsed:
      g* ← World Model(o_t, ℓ̂_t, m)  [异步，非阻塞]
  if Ĥ steps elapsed:
      a_{t:t+H} ← VLA(o_{t-T:t}, C_t)  [含 CFG + RTC]
  execute a_t
```

## 9. 设计选择的直觉解释

| 设计决策 | 核心原因 |
|---|---|
| KI（梯度不流回 VLM）| CFM 是近似下界，信号不稳定；VLM 预训练表征宝贵，保护其只接受离散 CE 训练 |
| World Model 独立训练 | BAGEL 14B 太大，联合训练不现实；解耦使 World Model 可以利用任意 web 图像编辑数据 |
| Subgoal 仅在 25% 样本中出现 | Subgoal 大幅简化了动作预测（类逆动力学问题）；过多注入使模型过依赖 subgoal，无 subgoal 时性能崩溃 |
| Episode Metadata + CFG | 混合质量数据用 metadata 消歧；CFG 在推理时将动作分布向高质量模式推移，等效于"无 RL 的 RL 效果" |
| High-Level Policy 同架构 | 子任务规划与动作控制均是序列预测问题；共享架构设计但独立训练，语义层与运动层解耦 |
| 训练时混入生成 subgoal | 弥合真实帧（训练）与生成帧（推理）的分布差距（train-test mismatch） |

## 10. 严谨数学符号定义

| 符号 | 含义 |
|---|---|
| $\pi_\theta$ | VLA 策略（θ 为全部参数，含 VLM 骨干 + Action Expert）|
| $g_\psi$ | World Model（ψ 为参数，BAGEL 初始化）|
| $\mathbf{o}_t = [\mathbf{I}_t^1,\ldots,\mathbf{I}_t^n, \mathbf{q}_t]$ | 当前时刻观测：$n$ 路图像 + 关节角 $\mathbf{q}_t$（本体感觉）|
| $\mathbf{a}_{t:t+H}$ | Action chunk，$H=50$ 步，连续关节/末端执行器命令 |
| $\hat{H} \in \{15, 25\}$ | 实际执行步数（$< H$，剩余部分丢弃）|
| $\mathcal{C}_t$ | 当前时刻的多模态 Prompt：$\{\ell_t, \hat{\ell}_t, \mathbf{g}_t, m, c\}$ |
| $\ell_t$ | 总任务语言指令（如 "clean the kitchen"）|
| $\hat{\ell}_t$ | 子任务语言指令（如 "open the fridge door"）|
| $\mathbf{g}_t = [G_t^1,\ldots,G_t^n]$ | 多视角子目标图像 |
| $\mathbf{g}_t^\star$ | Ground truth subgoal（segment 末帧）|
| $m = \{\text{speed}, \text{quality}, \text{mistake}\}$ | Episode metadata |
| $c \in \{\text{joint}, \text{ee}\}$ | 控制模式（关节空间 / 末端执行器空间）|
| $\tau \sim \mathcal{U}[0,1]$ | 流匹配时间步 |
| $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0},\mathbf{I})$ | 流匹配起点噪声 |
| $v_\theta$ | Action Expert 参数化的向量场 |
| $\beta$ | CFG 引导强度，$\beta \in \{1.3, 1.7, 2.2\}$ |
| $\mathcal{D}$ | VLA 训练数据集（含高质量演示 + 低质量/失败 episode + 自主 rollout + 非机器人数据）|
| $\mathcal{D}_g$ | World Model 训练数据子集（高质量子任务标注片段 + web 数据）|
